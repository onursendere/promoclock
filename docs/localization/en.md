# English style guide (source language)

Register: second person "you", contractions allowed ("don't", "it's"), sentence case everywhere except proper nouns and meta titles (Title Case allowed in meta titles only).
Spelling: US English in product copy (the site is global; keep "color", "organize"), except the fixed line "Lovingly built with Claude in Shrewsbury, UK".
Tone: helpful, plain, specific. Numbers as digits. Oxford comma optional but consistent within a string.

Terms: "peak hours" / "off-peak"; "session limit" / "weekly limit"; "limits drain faster"; "deal" (nav "AI Deals"); "promo" only in casual contexts and the calendar; "student offer"; "free trial"; "verified"; "source"; "affiliate disclosure"; "AI tool"; "free plan"; "pricing from"; "last reviewed"; "alternatives".

UI rules: buttons are verbs ("Buy me a coffee", "Get the deal", "Browse all tools"); badges are nouns; nav items are 1–2 words.
Footer coffee: `footer.coffeeLead` = "Saved you the timezone math?" (muted line), `footer.buymeacoffee` = "Buy me a coffee" (button).
Meta titles: primary keyword first, brand last after " | PromoClock"; ≤ 60 chars total.
Meta descriptions: 120–160 chars, one or two full sentences, include the query term, end with a period.
Avoid: "leverage", "seamless", "cutting-edge", "unlock", "supercharge", "revolutionary", "game-changing", "in today's fast-paced world".
