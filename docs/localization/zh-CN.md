# 简体中文风格指南 (zh-CN)

语气：面向大陆用户的消费级科技产品文案，用“你”（不用“您”），简洁、直接、口语化但专业（参考 Notion / 飞书 中文文案）。按钮用动宾短语（“领取优惠”“请我喝咖啡”）。标签、徽章、表头用名词短语，尽量 ≤ 6 字。
标点：全角中文标点（，。：；？！“”）；中英文之间不加空格（统一：不加）；数字、百分号、时间用半角：“25%”“13:00–19:00 UTC”；日期“2026年9月14日”；范围用“–”或“至”；省略号“……”。
术语：AI 保留“AI”。deal → “优惠”（nav 写作“AI优惠”，无空格）。promo → 统一用“活动”。plan → 统一用“套餐”（Pro套餐、免费套餐；套餐名保留英文）。tool → “工具”。
元标题 ≤ 32 字，元描述 60–95 字。导航 ≤ 6 字。
