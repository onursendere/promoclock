# 日本語スタイルガイド (ja)

文体: 本文は「です・ます」調で統一。UI ラベル・見出し・バッジは体言止め（例:「ライブ特典」「ピーク時間帯」）。ボタンは動詞連用形＋名詞 or 短い命令形（「特典を見る」「コーヒーをおごる」）。
表記: 全角句読点「、。」、全角かぎ括弧「」。半角英数字と全角文字の間にスペースは入れない（「Claudeの」であって「Claude の」ではない）。長音は付ける（サーバー、ユーザー）。ただし慣用の「ブラウザ」は長音なし。数字・％・時刻は半角:「25%」「13:00〜19:00 UTC」（範囲は「〜」）。日付「2026年9月14日」。三点リーダー「…」。
外来語: AI はそのまま「AI」。deal は「特典」（「ディール」は使わない）。promo は「プロモーション」または「キャンペーン」→ 統一して「キャンペーン」。plan は「プラン」。tool は「ツール」。
メタタイトルは全角32文字以内、メタディスクリプションは60〜95文字。UI は短く（ナビ ≤ 8 文字）。
