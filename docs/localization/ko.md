# 한국어 스타일 가이드 (ko)

문체: 본문은 **합니다체**(~합니다/~입니다), 버튼·CTA는 **하세요체** 또는 명사형(“특가 받기”, “커피 한 잔 사주기”). 반말 금지. UI 라벨·배지·표 헤더는 명사형으로 짧게.
표기: 띄어쓰기 규범 준수(“AI 도구”, “피크 시간대”), 외래어 표기법(세션, 플랜, 프로모션, 브라우저). 숫자·%·시각은 반각: “25%”, “13:00–19:00 UTC”. 날짜 “2026년 9월 14일”. 말줄임표 “…”.
용어: AI는 “AI” 그대로. deal → “특가”(단, 한도 변경 소식 등 비할인 항목까지 포함하는 nav는 “AI 특가”로 통일). promo → “프로모션”. plan → “플랜”(요금제 대신, 벤더 명칭과 맞춤). tool → “도구”.
메타 타이틀 ≤ 32자(공백 포함), 메타 설명 70–120자. 내비 ≤ 8자.
