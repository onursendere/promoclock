## What type of AI coding tool do you need?

Pick the type before the brand: where the AI works matters more than which model it runs. Most tools now fall into 5 groups.

- **Terminal agents** (Claude Code, Codex CLI, Warp) read your repository, run commands and edit files from the shell. You review the diff in git.
- **AI code editors** (Cursor, Devin Desktop, Kiro) replace your editor with one built around agents. Devin Desktop stays compatible with VS Code settings, and Kiro is built on Code OSS.
- **IDE extensions** (GitHub Copilot, Cline, JetBrains AI) plug into the editor you already use.
- **Autonomous agents** (Devin, plus cloud modes in Copilot, Codex, Cursor and Kiro) take a ticket, work on a remote machine and return a pull request.
- **App builders** (Replit, Lovable, Bolt.new, v0, Base44) turn a prompt into a hosted app for people who don't code.

Billing differs too: Claude Code shares one usage pool with Claude chat, Copilot spends AI Credits worth $0.01 each, Kiro and Warp sell credits, and Cline passes model costs through at your own API rates.

## Which terminal coding agents are worth paying for?

Claude Code is our pick for terminal-first developers; Codex is better value if you already pay for ChatGPT, and Warp suits people who want a new terminal.

### Claude Code

Claude Code is Anthropic's agentic coding tool for the terminal, VS Code, JetBrains IDEs and the Claude desktop app. According to [Anthropic's pricing page](https://claude.com/pricing), it is included in every paid plan: Pro at $20/month ($200/year), Max 5x at $100/month and Max 20x at $200/month. Claude Free does not include it.

Claude Code shares one pool with Claude chat, measured per rolling 5-hour session plus a weekly cap. On May 6, 2026, Anthropic [doubled Claude Code's 5-hour limits](/deals/claude-code-5h-limits-doubled/) and exempted it from the weekday peak-hours slowdown on Pro and Max. Since September 14, its weekly limits are [permanently 25% higher](/deals/claude-code-weekly-plus25-permanent/). Claude chat still drains faster on weekdays, 13:00–19:00 UTC, as our [live peak-hours clock](/) shows; the [Claude usage limits guide](/blog/claude-usage-limits/) has the details.

Individual Pro and Max subscribers active on September 23 can claim [$100 or $250 in Claude Code cloud credit](/deals/claude-code-cloud-credit-2026/) until October 7, 2026. Best for: agent work across a whole repository.

### OpenAI Codex

OpenAI Codex is included in every ChatGPT plan: Free ($0), Go ($8/month), Plus ($20/month) and Pro ($100, $200 or $500 a month). It runs as a CLI, an extension for VS Code, Cursor and Windsurf, in the ChatGPT desktop and web apps, on iOS and in cloud sandboxes.

Codex limits are estimates. OpenAI estimates 10–100 local messages on its most capable Codex model, or 250–2,000 on its lightest one, per 5-hour window on Plus, shared with ChatGPT Work. Best for: developers already paying for ChatGPT.

### Warp

Warp is a terminal with a built-in coding agent, and its client has been open source under the AGPL since April 28, 2026. Warp Free includes the terminal and Agent CLI but no bundled AI usage, so you bring your own API key. Build costs $20/month with 1,500 credits and Max $200/month with 18,000. Best for: DevOps and terminal-heavy engineers.

## Which AI code editor should you switch to?

Cursor is our pick for professional developers who want one AI editor; Devin Desktop suits people juggling many agents, and Kiro suits teams that want specs first.

### Cursor

Cursor Hobby is free with no credit card and a limited number of Agent requests. According to [Cursor's pricing page](https://cursor.com/pricing), Pro costs $20/month, Pro+ $60/month with 3x Pro's Agent limits and Ultra $200/month with 20x; yearly billing saves 20%.

Cursor's own Grok and Composer models draw from a larger included pool, while Claude, GPT and Gemini bill at API rates. Cursor's docs estimate daily agent users spend $60–$100 a month in total usage, so budget beyond $20. Best for: professionals running agents all day.

### Devin Desktop (formerly Windsurf)

Windsurf became Devin Desktop through an update on June 2, 2026, keeping its editor, extensions, settings and prices. Devin Desktop Free includes a light quota and unlimited Tab completions; Pro is $20/month, Max $200/month, and Teams starts at $80/month plus $40 per full seat. Through October 16, 2026, [SWE-2 is free on Pro and Max](/deals/windsurf-swe-2-free-oct-2026/). Best for: developers supervising local and cloud agents from one board.

### Kiro

Kiro is AWS's spec-driven IDE: prompts become requirements, a design and a task list before agents write code. Kiro Free includes 50 credits a month; Pro is $20/month for 1,000 credits, Pro+ $40 for 2,000, Pro Max $100 for 5,000 and Power $200 for 10,000. Best for: teams that want documented intent behind AI-written code.

## Which AI assistants plug into the IDE you already use?

GitHub Copilot is the default for VS Code and most editors; Cline suits bring-your-own-key users, and JetBrains AI suits IntelliJ, PyCharm and Kotlin developers.

### GitHub Copilot

Copilot Free costs $0 with 2,000 code completions a month and limited chat and agent use. According to [GitHub's plans page](https://github.com/features/copilot/plans), Pro is $10/month with $15 in monthly AI Credits, Pro+ $39 with $70 and Max $100 with $200. Since June 1, 2026, chat, agents and code review spend AI Credits, while completions stay unlimited on paid plans.

Copilot works in VS Code, Visual Studio, JetBrains IDEs, Xcode, Eclipse, Neovim and Zed, plus github.com, a CLI and a desktop app. Best for: teams on GitHub and budget-minded developers.

### Cline

Cline is a free, open-source agent (Apache 2.0) for VS Code, JetBrains IDEs in early access, the terminal and a desktop beta. You pay only for models, through your own API keys, at-cost inference from Cline, or ClinePass at $9.99/month for open-weight models. Cline asks for approval before each edit or command. Best for: developers who want full model choice or local models.

### JetBrains AI

JetBrains AI covers completion, chat and the Junie agent across JetBrains IDEs, and can also run Claude Agent, Codex and Gemini CLI. AI Free includes unlimited completion and 3 AI Credits per 30 days; AI Pro costs $10/month with 10 credits and AI Ultimate $30/month with 35, at $1 per credit. All Products Pack subscribers get AI Pro included. Best for: Java, Kotlin and Python developers.

## Do you need an autonomous agent like Devin?

Only if you want to hand over whole tickets: Devin works on its own cloud machine and returns pull requests, though many coding tools now include similar cloud agents.

### Devin

Devin is Cognition's cloud software engineer, and one plan covers Devin Cloud, Devin Desktop and the Devin CLI. According to [Devin's pricing page](https://devin.ai/pricing), Free has a light quota without cloud agents, Pro at $20/month adds Devin Cloud, and Max at $200/month raises quotas. Teams assign work from Slack, Microsoft Teams, Linear or Jira. Best for: teams with migration and bug backlogs.

Check what you already have first: Copilot's cloud agent works from GitHub issues, Codex cloud runs tasks in isolated environments, Cursor's cloud agents open pull requests, and Kiro Web runs agents on paid Kiro plans.

## Which AI app builders work without coding?

Lovable is our pick for non-technical founders and Replit for builders who want hosting and mobile apps in one place; Bolt.new, v0 and Base44 cover narrower needs.

### Replit

Replit Starter is free with daily Agent credits and 1 published app, which goes offline after 30 days. Core costs $20/month ($18 billed annually) with $20 in credits, and Pro $100/month with $100. Since August 18, 2026, Free Mode lets Core and Pro subscribers do everyday Agent work on a lighter model without spending credits. Best for: building and hosting web and native mobile apps.

### Lovable

Lovable Free gives 5 build credits a day, capped at 30 a month; Pro starts at $25/month and Business at $50/month. Through October 31, 2026, [Lovable chat costs no credits up to a daily allowance](/deals/lovable-free-daily-chat-2026/). Best for: founders shipping full-stack web apps without a developer.

### Bolt.new

Bolt.new Free includes 1M tokens a month with a 300K daily cap, and Pro starts at $25/month with 10M tokens. Through October 14, 2026, the [Bolt Forge preview](/deals/bolt-forge-preview-2026/) gives Pro up to 50x more Forge usage free, and sign-ups for the $9/month Forge-only Lite plan stay open. Best for: web and Expo mobile apps.

### v0

v0 is Vercel's agent for React and Next.js apps. New v0 Free accounts get a one-time $5 credit and 7 messages a day; Plus is $30 per user per month and Business $100, billed separately from Vercel hosting. Best for: prototyping on Vercel.

### Base44

Base44, owned by Wix, includes 25 message credits a month and up to 5 apps on Free. Starter is $20/month ($16 billed yearly), Builder $50, Pro $100 and Elite from $200, with code export from Builder up. Best for: internal tools and client portals.

GitHub Copilot Free and Cursor Hobby are the best free starting points, and verified students should claim the free Copilot Student plan first.

- **Free tiers:** Copilot Free, Cursor Hobby, Devin Desktop Free, Codex in ChatGPT Free, Kiro Free and JetBrains AI Free. Cline and Warp are free if you bring your own API key, so you pay only your model provider.

Kiro gives 1,000 credits a month free for a year at eligible universities, 132 of them in September 2026. Lovable offers 50% off Pro and Base44 50% off Starter or Builder for up to 12 months.
- **Ended:** Cursor's [free year of Pro for students](/deals/cursor-student-pro-year/) closed to new sign-ups on June 25, 2026.
