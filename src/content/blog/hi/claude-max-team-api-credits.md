Claude Max और Team प्लान में अब Claude API के लिए मासिक क्रेडिट शामिल हैं: Max 5x पर $100, Max 20x पर $200 और Team पर पूल होकर $500 तक। इन्हें एक बार क्लेम करना होता है, ये आपके अपने ऐप और एजेंट के लिए हैं, Claude Code के लिए नहीं, और हर बिलिंग साइकल में एक्सपायर हो जाते हैं। नीचे दी गई सभी प्लान जानकारी और क़ीमतें 17 अक्टूबर 2026 तक की हैं और Anthropic के हेल्प सेंटर, प्राइसिंग पेजों और Claude Code चेंजलॉग से ली गई हैं।

## Claude के मासिक API क्रेडिट क्या हैं?

Claude के मासिक API क्रेडिट Max और Team सब्सक्रिप्शन के साथ मिलने वाले Claude Platform क्रेडिट हैं, जो Claude API पर अपने ऐप और एजेंट बनाने और चलाने के लिए हैं। ये आपकी चैट और Claude Code की लिमिट से अलग रहते हैं।

Anthropic ने 7 अक्टूबर 2026 को Claude Haiku 5.5 के साथ ये क्रेडिट घोषित किए और अगले कुछ दिनों में सब्सक्राइबर तक पहुँचाए। [Anthropic का प्राइसिंग पेज](https://claude.com/pricing) अब Max के नीचे “महीने के $100 से $200 के API क्रेडिट” और Team के नीचे महीने के $500 तक के पूल्ड API क्रेडिट लिस्ट करता है। Free, Pro और Enterprise प्लान को ये नहीं मिलते।

क्रेडिट एक जोड़ हैं, अदला-बदली नहीं। हेल्प सेंटर के मुताबिक़ Claude, Claude Code और Cowork में आपकी यूसेज लिमिट बिल्कुल पहले जैसी रहती हैं। ये उस Agent SDK क्रेडिट जैसे भी नहीं हैं जिसकी घोषणा Anthropic ने जून में की थी: उसी आर्टिकल के मुताबिक़ वह ऑफ़र उपलब्ध नहीं है।

## हर Claude प्लान में कितने API क्रेडिट मिलते हैं?

Max 5x में महीने के $100 और Max 20x में $200 मिलते हैं, और Team प्लान में हर Standard सीट पर $20 और हर Premium सीट पर $100, पूल होकर $500 तक।

| प्लान | प्लान की क़ीमत | मासिक API क्रेडिट |
|---|---|---|
| Free | $0 | कोई नहीं |
| Pro | $20/महीना या $200/साल | कोई नहीं |
| Max 5x | $100/महीना | $100 |
| Max 20x | $200/महीना | $200 |
| Team Standard सीट | $25/सीट/महीना, या सालाना बिलिंग पर $20 | हर सीट पर $20, पूल होकर, हर टीम पर $500 तक |
| Team Premium सीट | $125/सीट/महीना, या सालाना बिलिंग पर $100 | हर सीट पर $100, पूल होकर, हर टीम पर $500 तक |
| Enterprise | सालाना बिलिंग पर $20/सीट/महीना, साथ में API रेट पर यूसेज | कोई नहीं |

[Anthropic के हेल्प सेंटर](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans) के मुताबिक़ Team पूल ऐसे काम करता है:

- **हर टीम का एक बैलेंस।** तीन Standard सीट और दो Premium सीट से महीने के $260 बनते हैं। तीसरी Premium सीट जोड़ने पर अगला साइकल $360 का हो जाता है।
- **सीमा $500 है।** बड़ी टीमों को भी $500 ही मिलते हैं, जो किसी भी Team प्लान को मिलने वाली अधिकतम रक़म है।
- **डिस्काउंटेड Team प्लान भी गिने जाते हैं।** नॉनप्रॉफ़िट और Scientists Team प्लान को भी हर सीट पर वही $20 और $100 मिलते हैं।

अगर आप Max 5x से Max 20x पर जाते हैं, तो आपको तुरंत प्रोरेटेड क्रेडिट मिलता है और उसके बाद हर साइकल $200। दोनों टियर के बीच और क्या बदलता है, यह हमारी [Claude Pro vs Max तुलना](/blog/claude-pro-vs-max/) में है।

## Claude API क्रेडिट कैसे क्लेम करें?

Claude के API क्रेडिट आप एक बार, claude.ai की बिलिंग सेटिंग में अपने प्लान से एक Claude Console ऑर्गनाइज़ेशन लिंक करके क्लेम करते हैं। उसके बाद क्रेडिट हर बिलिंग साइकल में उसी ऑर्गनाइज़ेशन में आते हैं।

1. Max या Team पर सात दिन पूरे होने तक रुकें। नए सब्सक्राइबर इससे पहले क्लेम नहीं कर सकते।
2. वेब ब्राउज़र में claude.ai पर **Settings > Billing** (Max) या **Organization settings > Billing** (Team) खोलें।
3. **API credits** सेक्शन में **Link organization** चुनें, फिर वह Console ऑर्गनाइज़ेशन चुनें या बनाएं जिसे क्रेडिट मिलना चाहिए।
4. Supplemental Credit Terms पढ़ें और पुष्टि करें।
5. Console का बिलिंग पेज खोलें, Promotional credits के नीचे क्रेडिट देखें और एक API key बनाएं।

क्लिक करने से पहले कुछ नियम जान लें:

- **रोल।** Max में आपका सब्सक्राइबर होना ज़रूरी है; Team में Owner या Primary Owner। Console ऑर्गनाइज़ेशन में आपके पास Owner, Admin या Billing रोल होना चाहिए।
- **एक लिंक, स्थायी।** हर प्लान एक Console ऑर्गनाइज़ेशन से जुड़ता है, और हर ऑर्गनाइज़ेशन एक ही प्लान से क्रेडिट लेता है। आप लिंक ख़ुद नहीं बदल सकते, इसलिए वही ऑर्गनाइज़ेशन चुनें जिसमें आप बनाने वाले हैं।
- **कार्ड की ज़रूरत नहीं।** क्रेडिट क्लेम करने या इस्तेमाल करने के लिए Claude Platform पर पेमेंट मेथड जोड़ना ज़रूरी नहीं है।
- **मोबाइल सब्सक्राइबर।** iOS या Android पर ख़रीदे गए प्लान योग्य हैं, लेकिन क्लेम ब्राउज़र में claude.ai पर होता है।
- **एक ही ईमेल से आसानी।** Anthropic सुझाव देता है कि Console में उसी ईमेल से साइन इन करें जो आप claude.ai पर इस्तेमाल करते हैं।

## API क्रेडिट में क्या कवर है और क्या नहीं?

Claude के मासिक API क्रेडिट Claude API, Claude Managed Agents, Agent SDK और Console Playground को कवर करते हैं। इंटरैक्टिव Claude Code, Claude ऐप्स में एक्स्ट्रा यूसेज और दूसरे क्लाउड पर Claude इनमें शामिल नहीं हैं।

किसी भी उपलब्ध Claude मॉडल के साथ जो कवर है:

- Claude API, यानी Messages API और Message Batches API दोनों
- Claude Console में Playground
- [Claude Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview), Anthropic का होस्टेड एजेंट हार्नेस, जो अब बीटा में है
- Claude Agent SDK, और `claude -p` जब आप उसे लिंक किए गए ऑर्गनाइज़ेशन की API key से चलाएं

जो कवर नहीं है:

- टर्मिनल, IDE, डेस्कटॉप ऐप या वेब पर इंटरैक्टिव Claude Code
- Claude, Claude Code या Cowork में एक्स्ट्रा यूसेज (यूसेज क्रेडिट)
- Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry पर Claude, या Claude Platform on AWS

## Claude Code के किन अपडेट से यूसेज लिमिट ज़्यादा टिकती है?

अक्टूबर 2026 के चार Claude Code बदलाव यूसेज बचाते हैं: आइडल कॉम्पैक्शन, हर सबएजेंट के लिए अलग effort और मॉडल, `/usage` की नई चेतावनियाँ, और वेब सर्च बजट जो फिर से भर जाता है। ये सब आपके मौजूदा प्लान की लिमिट के अंदर काम करते हैं।

- **आइडल कॉम्पैक्शन (वर्शन 2.1.299, 14 अक्टूबर)।** 200K टोकन से लंबी टर्मिनल बातचीत, जो क़रीब 54 मिनट आइडल रहती है, उसका कॉम्पैक्शन एक घंटे वाला प्रॉम्प्ट कैश एक्सपायर होने से ठीक पहले हो जाता है। जब आप लौटते हैं, तो Claude पूरी बातचीत की जगह सिर्फ़ सारांश दोबारा प्रोसेस करता है। इसे बंद करने के लिए settings.json में `"idleCompaction": false` सेट करें, या वर्शन 2.1.302 से `/config` में Idle compaction वाली पंक्ति इस्तेमाल करें।
- **हर सबएजेंट के लिए effort और मॉडल (2.1.292, 6 अक्टूबर)।** आप अपने प्रॉम्प्ट में कह सकते हैं कि कोडबेस खँगालने के लिए कम-effort वाले सबएजेंट चलें और नतीजे परखने के लिए एक ज़्यादा-effort वाला सबएजेंट, या तेज़ लुकअप के लिए Haiku। पहले इसके लिए कस्टम सबएजेंट डेफ़िनिशन चाहिए होती थी।
- **यूसेज चेतावनियाँ (2.1.299)।** `/usage` अब max effort, वर्कफ़्लो, हमेशा-ऑन कॉन्टेक्स्ट और बड़े टूल नतीजों को फ़्लैग करता है, जो सेशन जल्दी ख़त्म होने के आम कारण हैं।
- **वेब सर्च बजट (2.1.290, 5 अक्टूबर)।** इंटरैक्टिव सेशन को अब हर घंटे 100 सर्च मिलते हैं जो फिर भर जाते हैं, पहले की तरह 200 पर रुकने की जगह।

Anthropic के इंजीनियर एक प्रॉम्प्ट टिप जोड़ते हैं: सबएजेंट डिफ़ॉल्ट रूप से पूरी छानबीन को तरजीह देते हैं, इसलिए अपने प्रॉम्प्ट में एक वाक्य लिख दें कि समय मायने रखता है, तो वे तेज़ी से काम करते हैं, जिसे Anthropic स्पीड और क्वालिटी के बीच वाजिब संतुलन कहता है। 5 घंटे के सेशन और साप्ताहिक कैप कैसे काम करते हैं, यह जानने के लिए हमारी [Claude यूसेज लिमिट](/blog/claude-usage-limits/) गाइड देखें, और वीकडे पर लंबे चैट सेशन से पहले [Claude Watch](/) देख लें।

अगर आप Max या Team पर हैं और API पर कुछ भी बना सकते हैं, तो क्रेडिट क्लेम करें। क्लेम करने में कुछ ख़र्च नहीं होता, लेकिन ऑर्गनाइज़ेशन का लिंक बाद में सिर्फ़ सपोर्ट ही बदल सकता है।

- **API पर बनाने वाले Max सब्सक्राइबर:** वही Console ऑर्गनाइज़ेशन लिंक करें जो आप सच में इस्तेमाल करते हैं, क्योंकि इसे आप ख़ुद नहीं बदल सकते। महीने के $100 या $200 में Haiku 5.5 और Sonnet 5.5 का काफ़ी काम निकल जाता है।
- **सिर्फ़ Claude Code इस्तेमाल करने वाले Max सब्सक्राइबर:** क्रेडिट से आपकी लिमिट नहीं बढ़ेंगी। आइडल कॉम्पैक्शन, Haiku 5.5 सबएजेंट और नई `/usage` चेतावनियाँ बढ़ाएँगी।
- **Max 5x पर विचार करने वाले Pro यूज़र:** Max 5x, Pro से महीने के $80 ज़्यादा है और इसमें $100 का API क्रेडिट शामिल है, इसलिए अगर आप API पर पहले से इतना ख़र्च करते हैं तो यह सबसे जल्दी वसूल होता है।
- **Team Owner:** एक Owner पूरी टीम के लिए क्लेम करता है; वर्कस्पेस स्पेंड लिमिट सेट करें ताकि कोई एक प्रोजेक्ट पूल ख़ाली न कर दे।
- **ओपन-सोर्स मेंटेनर:** Claude for Open Source के लिए अप्लाई करें और, क्रिटिकल प्रोजेक्ट के लिए, OSS Scanner के लिए।

शर्तों में कोई भी बदलाव हमारे [API क्रेडिट ऑफ़र पेज](/deals/claude-max-team-api-credits-2026/) पर ट्रैक किया जाता है, और Claude के बाक़ी सभी ऑफ़र हमारे [Claude पेज](/tools/claude/) और [प्रोमो कैलेंडर](/calendar/) पर हैं।
