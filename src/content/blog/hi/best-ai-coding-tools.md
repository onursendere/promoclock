## आपको किस तरह का AI कोडिंग टूल चाहिए?

ब्रांड से पहले टाइप चुनें: AI कहाँ काम करता है, यह इससे ज़्यादा मायने रखता है कि वह कौन-सा मॉडल चलाता है। ज़्यादातर टूल अब 5 ग्रुप में आते हैं।

- **टर्मिनल एजेंट** (Claude Code, Codex CLI, Warp) शेल से आपकी रिपॉज़िटरी पढ़ते हैं, कमांड चलाते हैं और फ़ाइलें एडिट करते हैं। आप diff की समीक्षा git में करते हैं।
- **AI कोड एडिटर** (Cursor, Devin Desktop, Kiro) आपके एडिटर की जगह एजेंट के इर्द-गिर्द बना एडिटर ले आते हैं। Devin Desktop, VS Code सेटिंग के साथ कम्पैटिबल रहता है, और Kiro, Code OSS पर बना है।
- **IDE एक्सटेंशन** (GitHub Copilot, Cline, JetBrains AI) उसी एडिटर में जुड़ जाते हैं जो आप पहले से इस्तेमाल करते हैं।
- **ऑटोनॉमस एजेंट** (Devin, साथ में Copilot, Codex, Cursor और Kiro के क्लाउड मोड) एक टिकट लेते हैं, रिमोट मशीन पर काम करते हैं और पुल रिक्वेस्ट लौटाते हैं।
- **ऐप बिल्डर** (Replit, Lovable, Bolt.new, v0, Base44) कोडिंग न जानने वालों के लिए एक प्रॉम्प्ट को होस्ट किए गए ऐप में बदल देते हैं।

बिलिंग भी अलग-अलग है: Claude Code, Claude चैट के साथ एक ही यूसेज पूल शेयर करता है, Copilot $0.01 प्रति क्रेडिट वाले AI Credits ख़र्च करता है, Kiro और Warp क्रेडिट बेचते हैं, और Cline मॉडल का ख़र्च आपकी अपनी API रेट पर सीधे आप तक पहुँचाता है।

## कौन-से टर्मिनल कोडिंग एजेंट पैसे देने लायक़ हैं?

टर्मिनल-फ़र्स्ट डेवलपर के लिए हमारी पसंद Claude Code है; अगर आप पहले से ChatGPT के लिए भुगतान करते हैं तो Codex ज़्यादा फ़ायदेमंद है, और नया टर्मिनल चाहने वालों के लिए Warp ठीक है।

### Claude Code

Claude Code, Anthropic का एजेंटिक कोडिंग टूल है, जो टर्मिनल, VS Code, JetBrains IDE और Claude डेस्कटॉप ऐप में चलता है। [Anthropic के प्राइसिंग पेज](https://claude.com/pricing) के मुताबिक़ यह हर पेड प्लान में शामिल है: $20/महीना ($200/साल) वाला Pro, $100/महीना वाला Max 5x और $200/महीना वाला Max 20x। Claude Free में यह शामिल नहीं है।

Claude Code, Claude चैट के साथ एक ही पूल शेयर करता है, जिसे रोलिंग 5 घंटे के सेशन और एक साप्ताहिक सीमा में मापा जाता है। 6 मई 2026 को Anthropic ने [Claude Code की 5 घंटे की लिमिट दोगुनी की](/deals/claude-code-5h-limits-doubled/) और Pro व Max पर इसे सोमवार–शुक्रवार के पीक आवर्स वाली कटौती से छूट दी। 14 सितंबर से इसकी साप्ताहिक लिमिट [स्थायी रूप से 25% ज़्यादा](/deals/claude-code-weekly-plus25-permanent/) है। जैसा हमारी [लाइव पीक आवर्स घड़ी](/) दिखाती है, Claude चैट अब भी सोमवार से शुक्रवार 13:00–19:00 UTC में तेज़ी से ख़त्म होती है; पूरी जानकारी [Claude यूसेज लिमिट गाइड](/blog/claude-usage-limits/) में है।

23 सितंबर को एक्टिव रहे इंडिविजुअल Pro और Max सब्सक्राइबर 7 अक्टूबर 2026 तक [$100 या $250 का Claude Code क्लाउड क्रेडिट](/deals/claude-code-cloud-credit-2026/) क्लेम कर सकते हैं। किनके लिए: पूरी रिपॉज़िटरी पर एजेंट वाला काम।

### OpenAI Codex

OpenAI Codex हर ChatGPT प्लान में शामिल है: Free ($0), Go ($8/महीना), Plus ($20/महीना) और Pro ($100, $200 या $500 प्रति महीना)। यह CLI के रूप में, VS Code, Cursor और Windsurf के एक्सटेंशन के रूप में, ChatGPT के डेस्कटॉप और वेब ऐप में, iOS पर और क्लाउड सैंडबॉक्स में चलता है।

Codex की लिमिट अनुमान भर हैं। OpenAI के अनुमान के मुताबिक़ Plus पर हर 5 घंटे की विंडो में इसके सबसे सक्षम Codex मॉडल पर 10–100 लोकल मैसेज, या सबसे हल्के मॉडल पर 250–2,000 मैसेज मिलते हैं, जो ChatGPT Work के साथ शेयर होते हैं। किनके लिए: पहले से ChatGPT के लिए भुगतान करने वाले डेवलपर।

## कौन-से AI असिस्टेंट आपके मौजूदा IDE में जुड़ जाते हैं?

VS Code और ज़्यादातर एडिटर के लिए GitHub Copilot डिफ़ॉल्ट विकल्प है; अपनी API key ख़ुद लगाने वालों के लिए Cline ठीक है, और IntelliJ, PyCharm और Kotlin डेवलपर के लिए JetBrains AI।

### GitHub Copilot

Copilot Free की क़ीमत $0 है, जिसमें महीने में 2,000 कोड कम्प्लीशन और सीमित चैट व एजेंट इस्तेमाल मिलता है। [GitHub के प्लान पेज](https://github.com/features/copilot/plans) के मुताबिक़ Pro $10/महीना है जिसमें हर महीने $15 के AI Credits मिलते हैं, Pro+ $39 है जिसमें $70 के, और Max $100 है जिसमें $200 के। 1 जून 2026 से चैट, एजेंट और कोड रिव्यू में AI Credits ख़र्च होते हैं, जबकि पेड प्लान पर कम्प्लीशन अनलिमिटेड रहते हैं।

Copilot, VS Code, Visual Studio, JetBrains IDE, Xcode, Eclipse, Neovim और Zed में काम करता है, साथ ही github.com, एक CLI और एक डेस्कटॉप ऐप में भी। किनके लिए: GitHub पर काम करने वाली टीमें और बजट का ध्यान रखने वाले डेवलपर।

### Cline

### JetBrains AI

JetBrains AI, JetBrains IDE में कम्प्लीशन, चैट और Junie एजेंट देता है, और Claude Agent, Codex और Gemini CLI भी चला सकता है। AI Free में अनलिमिटेड कम्प्लीशन और हर 30 दिन में 3 AI Credits मिलते हैं; AI Pro की क़ीमत 10 क्रेडिट के साथ $10/महीना और AI Ultimate की 35 क्रेडिट के साथ $30/महीना है, यानी $1 प्रति क्रेडिट। All Products Pack सब्सक्राइबर को AI Pro शामिल मिलता है। किनके लिए: Java, Kotlin और Python डेवलपर।
