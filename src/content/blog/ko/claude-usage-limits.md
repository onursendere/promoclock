Claude의 사용 한도는 두 단계로 작동합니다. 모든 플랜에 5시간 단위로 초기화되는 세션 한도가 있고, 유료 플랜에는 그 위에 주간 한도가 더해집니다. 채팅과 Claude Code는 같은 풀을 쓰며, 평일 13:00–19:00 UTC에는 세션 한도가 더 빨리 소진됩니다. 2026년 10월 기준 한도가 작동하는 방식, Anthropic이 올해 바꾼 모든 내용, 한도를 오래 쓰는 방법을 정리했습니다.

## Claude 사용 한도는 어떻게 작동할까?

[Anthropic 요금 페이지](https://claude.com/pricing)에 따르면 Claude의 사용 한도는 5시간 단위 세션으로 초기화되고, 유료 플랜에는 주간 한도가 더해집니다. 고정된 메시지 수는 없습니다.

핵심 규칙은 세 가지입니다.

- **세션 한도:** Free를 포함한 모든 플랜에 5시간 세션당 사용량이 정해져 있습니다.
- **주간 한도:** 유료 플랜에는 주간 한도도 있습니다. Max에서는 모든 모델에 걸쳐 적용됩니다.
- **하나의 풀:** 웹, 데스크톱, 모바일의 Claude와 Claude Code는 같은 사용량을 공유합니다. 긴 코딩 세션도 긴 채팅과 같은 한도를 깎아 먹습니다.

메시지 하나가 사용량을 얼마나 쓰는지는 요청 내용에 따라 다릅니다. Anthropic의 [사용 한도 모범 사례](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)는 메시지 길이, 첨부 파일 크기, 현재 대화 길이, Research와 웹 검색 같은 도구, 모델 선택, effort 수준, 아티팩트, 코드 실행이나 웹사이트 탐색 같은 다단계 작업을 요인으로 꼽습니다.

## Claude 한도는 언제 초기화될까?

Claude의 세션 한도는 5시간마다, 주간 한도는 계정마다 정해진 매주 같은 시각에 초기화됩니다. 두 초기화 시각 모두 Claude의 Settings > Usage에서 볼 수 있습니다.

주간 초기화 시점은 사람마다 다르므로, 친구의 초기화 요일로는 내 초기화 시점을 알 수 없습니다. Anthropic은 [Max 플랜 도움말](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)에서 주간 초기화 시점을 설명합니다. 세션 한도에 걸렸다면 다음 5시간 초기화를 기다리면 됩니다. 주간 한도에 걸렸다면 주간 초기화가 올 때까지 세션 초기화는 도움이 되지 않습니다.

## Claude 플랜별 사용량은 어떻게 다를까?

Claude Pro는 5시간 세션당 Free의 최소 5배 사용량을 제공하고, Max는 Pro의 5배 또는 20배를 제공합니다. 아래 가격은 2026년 10월 기준 Anthropic 공식 가격입니다.

| 플랜 | 가격 | 5시간 세션당 사용량 | Claude Code | 사용 크레딧 |
|---|---|---|---|---|
| Free | $0 | 기준 | 미포함 | 불가 |
| Pro | 월 $20, 연간 결제 시 월 $17($200 선결제) | Free의 최소 5배 | 포함 | 가능 |
| Max 5x | 월 $100 | Pro의 5배 | 포함 | 가능 |
| Max 20x | 월 $200 | Pro의 20배 | 포함 | 가능 |

Max는 월간 결제만 가능합니다. Team Standard 좌석은 월 $25, 연간 결제 시 월 $20이며, Team과 좌석 기반 Enterprise 플랜에는 별도의 사용 크레딧 설정이 있습니다.

어떤 작업량에 어떤 등급이 맞는지는 [Claude Pro vs Max 비교](/blog/claude-pro-vs-max/)에서 자세히 다룹니다.

## Claude Code 사용 한도는?

Claude Code는 채팅과 같은 5시간 한도와 주간 한도를 쓰지만, Anthropic은 2026년에 Claude Code 한도만 따로 여러 차례 바꿨습니다. 2026년 10월 기준 Claude Code에는 두 배로 늘어난 5시간 한도, 영구적인 주간 한도 상향, Pro와 Max에서의 피크 시간대 제외가 적용됩니다.

- **5시간 한도:** Anthropic의 [공식 발표](https://www.anthropic.com/news/higher-limits-spacex)에 따르면 2026년 5월 6일 유료 플랜의 [Claude Code 5시간 한도가 두 배로 늘었습니다](/deals/claude-code-5h-limits-doubled/).
- **피크 시간대:** 같은 업데이트로 Pro와 Max의 Claude Code에 적용되던 피크 시간대 한도 감소가 사라졌습니다.
- **주간 한도:** 2026년 5월 13일부터 9월 14일까지 [주간 한도 +50% 상향](/deals/claude-code-weekly-plus50-2026/)이 적용됐고, 이후 [영구 +25%](/deals/claude-code-weekly-plus25-permanent/)로 대체됐습니다. 기준을 100으로 보면 프로모션 전 100, 프로모션 중 150, 현재 125입니다.
- **클라우드 세션:** 개인 Pro 구독자는 $100, Max 구독자는 $250의 [Claude Code 클라우드 크레딧](/deals/claude-code-cloud-credit-2026/)을 받으며, 클라우드 세션은 플랜 한도보다 이 크레딧을 먼저 씁니다. 2026년 10월 7일까지 신청해야 하고, 쓰지 않은 크레딧은 2026년 11월 4일에 만료됩니다.

Free 플랜에는 Claude Code가 포함되지 않습니다.

## 피크 시간대는 Claude 사용 한도에 어떤 영향을 줄까?

Claude 피크 시간대인 평일 13:00–19:00 UTC에는 Free, Pro, Max, Team 플랜의 5시간 세션 한도가 더 빨리 소진됩니다. 주간 한도는 영향을 받지 않습니다.

[피크 시간대는 2026년 3월 27일부터 적용됐습니다](/deals/claude-peak-hours-introduced/). [The Register 보도](https://www.theregister.com/2026/03/26/anthropic_tweaks_usage_limits/)에 따르면 당시 Anthropic의 Thariq Shihipar는 사용자의 약 7%가 이전에는 닿지 않던 세션 한도에 도달할 것으로 추정했습니다.

Enterprise 플랜은 영향을 받지 않고, Pro와 Max의 Claude Code는 적용 대상에서 제외됩니다. [Claude 피크 시간대 가이드](/blog/claude-peak-hours/)에서 9개 시간대의 현지 시각을 확인할 수 있고, [Claude Watch](/)에서 지금 피크 시간대인지 볼 수 있습니다.

## 어떤 모델을 쓰느냐에 따라 한도 소진 속도가 달라질까?

네. Anthropic은 모델 선택을 사용량 요인으로 꼽으며, Fable 모델은 다른 Claude 모델보다 한도를 더 빨리 씁니다.

- **Max의 Fable 5와 Fable 5.1:** 포함되지만, Anthropic의 [Fable 플랜 도움말](https://support.claude.com/en/articles/15424964-claude-fable-models-on-your-plan)에 따르면 추가 비용 없이 Fable 모델에 쓸 수 있는 것은 주간 한도의 최대 50%입니다. Team과 Enterprise의 프리미엄 좌석도 같은 방식입니다.
- **Pro와 Team 표준 좌석의 Fable:** 2026년 7월부터 플랜 한도에 포함되지 않습니다. 사용 크레딧으로는 계속 Fable을 쓸 수 있습니다.
- **Opus:** Pro와 Max에는 포함되지만 Free에는 없습니다.
- **Sonnet과 Haiku:** Anthropic은 사용 크레딧 도움말에서 Haiku를 가장 효율적인 모델이라고 부르며, 대부분의 작업에 Haiku나 최신 Sonnet을 권합니다.

PromoClock의 추천은 이렇습니다. Sonnet을 기본으로 쓰고, Sonnet이 풀지 못하는 문제에만 Opus나 Fable로 바꾸고, 일상적인 작업에는 effort 수준을 낮추세요.

## Claude 사용 한도에 도달하면 어떻게 해야 할까?

Claude 사용 한도에 도달하면 초기화를 기다리거나, 작업 방식을 바꾸거나, 사용 크레딧을 켜거나, 더 큰 플랜으로 옮길 수 있습니다.

1. **어떤 한도에 걸렸는지 확인하세요.** Settings > Usage에서 세션 한도인지 주간 한도인지, 언제 초기화되는지 볼 수 있습니다.
2. **피크 시간대가 끝나기를 기다리세요.** 평일 13:00–19:00 UTC 사이라면, 19:00 UTC 이후의 다음 세션은 더 오래 갑니다.
3. **모델을 바꾸세요.** Max에서 Fable 상한에 도달해도 Claude가 멈추지는 않으니 다른 모델로 바꾸면 됩니다.
4. **사용 크레딧을 켜세요.** 아래에서 설명합니다.
5. **반복된다면 업그레이드하세요.** 거의 매주 주간 한도에 걸린다면 Max 5x나 Max 20x가 필요하다는 신호입니다.

### Claude 사용 크레딧은 어떻게 작동할까?

Claude 사용 크레딧을 쓰면 Pro, Max 5x, Max 20x 구독자는 플랜 한도에 도달한 뒤에도 표준 API 요금으로 계속 작업할 수 있습니다. 설정 방법은 Anthropic의 [사용 크레딧 도움말](https://support.claude.com/en/articles/12429409-manage-usage-credits-for-paid-claude-plans)에 나와 있습니다.

- Settings > Usage로 가서 Enable을 클릭하고, 결제 수단을 추가한 뒤 금액을 선불로 충전합니다.
- 월 지출 상한을 정하고, 원하면 잔액이 부족할 때 자동 충전되도록 설정합니다.
- 크레딧은 Claude 대화, Claude Code, Research에 쓸 수 있습니다.
- Anthropic은 사용량 번들 구매도 선택지로 안내합니다.

크레딧은 청구서에 별도 항목으로 표시됩니다. 비용이 신경 쓰인다면 [AI 구독료 절약 가이드](/blog/save-money-on-ai-subscriptions/)에서 연간 결제를 비롯해 덜 내는 방법을 확인하세요.

## Claude 사용 한도를 더 오래 쓰려면?

가장 효과가 큰 것은 시간대, 짧은 대화, 알맞은 모델입니다. 아래 팁은 Anthropic의 안내와 앞서 본 2026년 변경 사항을 바탕으로 합니다.

- **비피크에 작업하세요.** 긴 문서, Research, 대용량 업로드는 평일 13:00–19:00 UTC 밖에서 세션 한도를 덜 씁니다.
- **새 채팅을 시작하세요.** 대화 길이도 사용량에 반영되므로 주제가 바뀌면 새 채팅을 여세요.
- **질문을 묶으세요.** 요청을 미리 정리하고, 구체적인 메시지 하나에 관련 질문을 함께 담으세요.
- **참고 파일은 프로젝트에 넣으세요.** Anthropic에 따르면 프로젝트에 캐시된 콘텐츠는 한도에 더 적게 반영됩니다.
- **더 가벼운 모델을 고르세요.** Sonnet을 기본으로 쓰고, 간단한 작업에는 effort 수준을 낮추세요.
- **도구는 필요할 때만 쓰세요.** Research와 웹 검색은 사용량을 늘리므로 답에 꼭 필요할 때 켜세요.
- **진행 중인 프로모션을 활용하세요.** 2026년 10월 15일까지 Pro, Max, Team에서 아티팩트로 작업하면 세션 사용량이 50% 적게 듭니다.

## 결론: 플랜별로 한도를 어떻게 관리할까?

Claude의 한도는 5시간 세션 한도와 주간 한도로 이뤄지며, 어떤 플랜을 쓰느냐만큼 언제 쓰느냐도 중요합니다.

- **Free 사용자:** 채팅을 짧게 유지하고 피크 시간대 밖에서 작업하세요. 매일 한도에 걸린다면 Pro로 올리면 됩니다.
- **Pro 사용자:** Sonnet을 기본으로 쓰고, 어쩌다 한도를 넘는 날에는 사용 크레딧을 더하세요. Claude Code는 피크 시간대 적용 대상에서 제외됩니다.
- **주간 한도에 걸리는 Pro 헤비 유저:** Max 5x(월 $100)는 Pro의 5배 세션 사용량을 제공합니다.
- **Max 사용자:** Fable 50% 상한에 주의하고, 2026년 10월 7일까지 $250 클라우드 크레딧을 신청하세요.
- **팀:** Anthropic이 Team의 Claude Code에 대한 피크 시간대 제외를 발표하지 않았으므로, 대규모 작업은 비피크로 잡으세요.

PromoClock은 [Claude Watch](/)에서 Claude의 모든 한도 변경을 실시간으로 추적합니다.
