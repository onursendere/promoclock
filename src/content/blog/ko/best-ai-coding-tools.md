## 나에게 맞는 AI 코딩 도구 유형은?

브랜드보다 유형을 먼저 고르는 것이 좋습니다. 어떤 모델을 쓰는지보다 AI가 어디에서 일하는지가 더 중요하기 때문입니다. 요즘 도구 대부분은 다섯 가지 유형으로 나뉩니다.

- **터미널 에이전트**(Claude Code, Codex CLI, Warp)는 셸에서 저장소를 읽고, 명령을 실행하고, 파일을 수정합니다. 변경 내용(diff)은 git에서 검토합니다.
- **AI 코드 에디터**(Cursor, Devin Desktop, Kiro)는 기존 에디터를 에이전트 중심으로 만든 에디터로 대체합니다. Devin Desktop은 VS Code 설정과 호환되고, Kiro는 Code OSS 기반입니다.
- **IDE 확장 프로그램**(GitHub Copilot, Cline, JetBrains AI)은 이미 쓰는 에디터에 설치해 씁니다.
- **자율 에이전트**(Devin, 그리고 Copilot, Codex, Cursor, Kiro의 클라우드 모드)는 티켓을 받아 원격 머신에서 작업한 뒤 풀 리퀘스트를 돌려줍니다.
- **앱 빌더**(Replit, Lovable, Bolt.new, v0, Base44)는 코딩을 하지 않는 사람을 위해 프롬프트를 호스팅된 앱으로 바꿔 줍니다.

과금 방식도 다릅니다. Claude Code는 Claude 채팅과 하나의 사용량 풀을 공유하고, Copilot은 개당 $0.01인 AI Credits를 차감하며, Kiro와 Warp는 크레딧을 판매하고, Cline은 모델 비용을 본인 API 요금 그대로 넘깁니다.

## 돈을 낼 만한 터미널 코딩 에이전트는?

터미널 중심 개발자에게는 Claude Code를 추천합니다. 이미 ChatGPT 요금을 낸다면 Codex가 더 경제적이고, 새 터미널을 원한다면 Warp가 맞습니다.

### Claude Code

Claude Code는 터미널, VS Code, JetBrains IDE, Claude 데스크톱 앱에서 쓰는 Anthropic의 에이전트형 코딩 도구입니다. [Anthropic 요금 페이지](https://claude.com/pricing)에 따르면 모든 유료 플랜에 포함됩니다. Pro는 월 $20(연 $200), Max 5x는 월 $100, Max 20x는 월 $200입니다. Claude Free에는 포함되지 않습니다.

Claude Code는 Claude 채팅과 하나의 풀을 공유하며, 사용량은 5시간 단위로 갱신되는 세션과 주간 상한으로 측정됩니다. 2026년 5월 6일 Anthropic은 [Claude Code의 5시간 한도를 두 배로 늘리고](/deals/claude-code-5h-limits-doubled/) Pro와 Max에서 평일 피크 시간대 한도 감소 대상에서 제외했습니다. 9월 14일부터는 주간 한도가 [영구적으로 25% 높아졌습니다](/deals/claude-code-weekly-plus25-permanent/). [실시간 피크 시간대 시계](/)에서 보듯 Claude 채팅은 여전히 평일 13:00–19:00 UTC에 한도가 더 빨리 소진됩니다. 자세한 내용은 [Claude 사용 한도 가이드](/blog/claude-usage-limits/)에 있습니다.

9월 23일에 활성 상태였던 개인 Pro·Max 구독자는 2026년 10월 7일까지 [$100 또는 $250의 Claude Code 클라우드 크레딧](/deals/claude-code-cloud-credit-2026/)을 받을 수 있습니다. 추천 대상: 저장소 전체를 다루는 에이전트 작업.

### OpenAI Codex

OpenAI Codex는 모든 ChatGPT 플랜에 포함됩니다. Free($0), Go(월 $8), Plus(월 $20), Pro(월 $100, $200, $500)입니다. CLI, VS Code·Cursor·Windsurf용 확장 프로그램, ChatGPT 데스크톱·웹 앱, iOS, 클라우드 샌드박스에서 실행됩니다.

Codex 한도는 추정치입니다. OpenAI는 Plus 기준 5시간마다 가장 성능이 높은 Codex 모델로 로컬 메시지 10–100개, 가장 가벼운 모델로 250–2,000개를 쓸 수 있다고 추정하며, 이 한도는 ChatGPT Work와 공유됩니다. 추천 대상: 이미 ChatGPT 요금을 내는 개발자.

### Warp

Warp는 코딩 에이전트가 내장된 터미널이며, 클라이언트는 2026년 4월 28일부터 AGPL 라이선스의 오픈 소스입니다. Warp Free에는 터미널과 Agent CLI가 포함되지만 AI 사용량은 없으므로 본인의 API 키를 연결해야 합니다. Build는 1,500크레딧에 월 $20, Max는 18,000크레딧에 월 $200입니다. 추천 대상: DevOps와 터미널 작업이 많은 엔지니어.

## 어떤 AI 코드 에디터로 갈아탈까?

AI 에디터 하나로 통일하려는 전문 개발자에게는 Cursor를 추천합니다. 여러 에이전트를 동시에 다룬다면 Devin Desktop, 스펙을 먼저 정하고 싶은 팀이라면 Kiro가 맞습니다.

### Cursor

Cursor Hobby는 신용카드 없이 무료이며 제한된 수의 Agent 요청을 제공합니다. [Cursor 요금 페이지](https://cursor.com/pricing)에 따르면 Pro는 월 $20, Pro+는 Pro의 3배 Agent 한도로 월 $60, Ultra는 20배로 월 $200이며, 연간 결제 시 20% 저렴합니다.

Cursor 자체 모델인 Grok과 Composer는 더 큰 포함 사용량 풀을 쓰고, Claude, GPT, Gemini는 API 요금으로 청구됩니다. Cursor 문서는 매일 에이전트를 쓰는 사용자의 총사용량이 월 $60–$100 정도라고 추정하므로 $20 이상의 예산을 잡아 두는 것이 좋습니다. 추천 대상: 하루 종일 에이전트를 돌리는 전문가.

### Devin Desktop(구 Windsurf)

Windsurf는 2026년 6월 2일 업데이트로 Devin Desktop이 됐으며 에디터, 확장 프로그램, 설정, 가격은 그대로입니다. Devin Desktop Free는 가벼운 할당량과 무제한 Tab 완성을 포함합니다. Pro는 월 $20, Max는 월 $200, Teams는 월 $80에 정규 좌석당 $40부터입니다. 2026년 10월 16일까지 [Pro와 Max에서 SWE-2가 무료](/deals/windsurf-swe-2-free-oct-2026/)입니다. 추천 대상: 로컬·클라우드 에이전트를 한 보드에서 관리하는 개발자.

### Kiro

Kiro는 AWS의 스펙 기반 IDE입니다. 에이전트가 코드를 쓰기 전에 프롬프트를 요구 사항, 설계, 작업 목록으로 바꿉니다. Kiro Free는 월 50크레딧을 포함하고, Pro는 1,000크레딧에 월 $20, Pro+는 2,000크레딧에 $40, Pro Max는 5,000크레딧에 $100, Power는 10,000크레딧에 $200입니다. 추천 대상: AI가 쓴 코드의 의도를 문서로 남기고 싶은 팀.

## 지금 쓰는 IDE에 붙는 AI 어시스턴트는?

VS Code와 대부분의 에디터에서는 GitHub Copilot이 기본 선택입니다. 본인 API 키를 쓰려면 Cline, IntelliJ·PyCharm·Kotlin 개발자라면 JetBrains AI가 맞습니다.

### GitHub Copilot

Copilot Free는 $0이며 월 2,000회 코드 완성과 제한된 채팅·에이전트 사용을 제공합니다. [GitHub 플랜 페이지](https://github.com/features/copilot/plans)에 따르면 Pro는 월 $15어치 AI Credits와 함께 월 $10, Pro+는 $70어치와 함께 $39, Max는 $200어치와 함께 $100입니다. 2026년 6월 1일부터 채팅, 에이전트, 코드 리뷰는 AI Credits를 차감하고, 코드 완성은 유료 플랜에서 계속 무제한입니다.

Copilot은 VS Code, Visual Studio, JetBrains IDE, Xcode, Eclipse, Neovim, Zed에서 작동하며 github.com, CLI, 데스크톱 앱에서도 쓸 수 있습니다. 추천 대상: GitHub를 쓰는 팀과 예산을 아끼려는 개발자.

### Cline

Cline은 VS Code, 얼리 액세스 단계의 JetBrains IDE, 터미널, 데스크톱 베타에서 쓰는 무료 오픈 소스 에이전트(Apache 2.0)입니다. 비용은 모델에만 들며, 본인 API 키, Cline의 원가 추론, 오픈 웨이트 모델용 월 $9.99의 ClinePass 중에서 고를 수 있습니다. Cline은 수정이나 명령을 실행할 때마다 먼저 승인을 요청합니다. 추천 대상: 모델을 자유롭게 고르거나 로컬 모델을 쓰고 싶은 개발자.

### JetBrains AI

JetBrains AI는 JetBrains IDE 전반에서 코드 완성, 채팅, Junie 에이전트를 제공하며 Claude Agent, Codex, Gemini CLI도 실행할 수 있습니다. AI Free는 무제한 코드 완성과 30일마다 AI Credits 3개를 포함합니다. AI Pro는 10크레딧에 월 $10, AI Ultimate는 35크레딧에 월 $30이며, 크레딧은 개당 $1입니다. All Products Pack 구독자에게는 AI Pro가 포함됩니다. 추천 대상: Java, Kotlin, Python 개발자.

## Devin 같은 자율 에이전트가 필요할까?

티켓 전체를 맡기고 싶을 때만 필요합니다. Devin은 자체 클라우드 머신에서 작업하고 풀 리퀘스트를 돌려주지만, 이제 많은 코딩 도구에 비슷한 클라우드 에이전트가 들어 있습니다.

### Devin

Devin은 Cognition의 클라우드 소프트웨어 엔지니어로, 플랜 하나로 Devin Cloud, Devin Desktop, Devin CLI를 모두 씁니다. [Devin 요금 페이지](https://devin.ai/pricing)에 따르면 Free는 클라우드 에이전트 없이 가벼운 할당량을 제공하고, 월 $20의 Pro는 Devin Cloud를 추가하며, 월 $200의 Max는 할당량을 늘립니다. 팀은 Slack, Microsoft Teams, Linear, Jira에서 작업을 배정합니다. 추천 대상: 마이그레이션과 버그가 밀려 있는 팀.

먼저 이미 가진 도구를 확인하세요. Copilot의 클라우드 에이전트는 GitHub 이슈에서 작업하고, Codex 클라우드는 격리된 환경에서 작업을 실행하며, Cursor의 클라우드 에이전트는 풀 리퀘스트를 열고, Kiro Web은 유료 Kiro 플랜에서 에이전트를 실행합니다.

## 코딩 없이 쓰는 AI 앱 빌더는?

비개발자 창업자에게는 Lovable을, 호스팅과 모바일 앱을 한곳에서 해결하려는 사람에게는 Replit을 추천합니다. Bolt.new, v0, Base44는 더 좁은 용도에 맞습니다.

### Replit

Replit Starter는 무료이며 매일 Agent 크레딧과 게시 앱 1개를 제공하고, 이 앱은 30일 후 오프라인이 됩니다. Core는 $20어치 크레딧과 함께 월 $20(연간 결제 시 $18), Pro는 $100어치 크레딧과 함께 월 $100입니다. 2026년 8월 18일부터 Core·Pro 구독자는 Free Mode로 크레딧을 쓰지 않고 더 가벼운 모델에서 일상적인 Agent 작업을 할 수 있습니다. 추천 대상: 웹 앱과 네이티브 모바일 앱의 개발·호스팅.

### Lovable

Lovable Free는 하루 5빌드 크레딧을 주며 월 30크레딧이 상한입니다. Pro는 월 $25, Business는 월 $50부터입니다. 2026년 10월 31일까지 [Lovable 채팅은 일일 한도 안에서 크레딧이 차감되지 않습니다](/deals/lovable-free-daily-chat-2026/). 추천 대상: 개발자 없이 풀스택 웹 앱을 출시하려는 창업자.

### Bolt.new

Bolt.new Free는 월 100만 토큰(하루 상한 30만 토큰)을 포함하고, Pro는 1,000만 토큰에 월 $25부터입니다. 2026년 10월 14일까지 [Bolt Forge 프리뷰](/deals/bolt-forge-preview-2026/)로 Pro 사용자는 최대 50배 많은 Forge 사용량을 무료로 쓸 수 있고, 월 $9의 Forge 전용 Lite 플랜 가입도 계속 열려 있습니다. 추천 대상: 웹과 Expo 모바일 앱.

### v0

v0는 React와 Next.js 앱을 만드는 Vercel의 에이전트입니다. 새 v0 Free 계정은 1회성 $5 크레딧과 하루 메시지 7개를 받습니다. Plus는 사용자당 월 $30, Business는 $100이며 Vercel 호스팅과 별도로 청구됩니다. 추천 대상: Vercel 기반 프로토타이핑.

### Base44

Wix가 소유한 Base44는 Free에서 월 메시지 크레딧 25개와 앱 최대 5개를 제공합니다. Starter는 월 $20(연간 결제 시 $16), Builder는 $50, Pro는 $100, Elite는 $200부터이며, Builder 이상에서 코드 내보내기가 가능합니다. 추천 대상: 사내 도구와 고객 포털.
