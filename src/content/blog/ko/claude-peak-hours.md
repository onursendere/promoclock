Claude의 피크 시간대는 평일 13:00–19:00 UTC입니다. 이 6시간 동안 Free, Pro, Max, Team 플랜의 5시간 세션 한도는 평소보다 빨리 소진되지만 주간 한도는 그대로이며, 평일 저녁과 밤, 그리고 주말 전체는 비피크입니다. 이 가이드는 2026년 10월 기준 규칙, 9개 도시의 피크 시간대, 무거운 작업을 피크 시간대 밖으로 옮기는 간단한 계획을 다룹니다.

## Claude 피크 시간대란?

Claude 피크 시간대는 Anthropic이 5시간 세션 한도를 더 빨리 소진되게 하는 평일의 고정 시간대, 13:00–19:00 UTC를 말합니다. 2026년 3월 27일부터 적용되고 있습니다.

- **피크:** 월요일부터 금요일까지 13:00–19:00 UTC.
- **비피크:** 평일의 나머지 모든 시간과 토요일·일요일 전체(UTC 기준).
- **종료일:** 발표되지 않았습니다. Anthropic은 이 시간대를 언제 없앨지, 없앨 계획이 있는지도 밝히지 않았습니다.

PromoClock 홈페이지의 [Claude Watch](/)에서 이 시간대를 실시간으로 추적합니다. 지금 Claude가 피크 시간대인지, 현지 시간 기준 피크 시간대, 다음 전환까지의 카운트다운을 보여 줍니다.

## Claude 피크 시간대에는 무엇이 달라질까?

달라지는 것은 5시간 세션 한도의 소진 속도뿐입니다. 피크 시간대에는 같은 작업이 세션 한도에서 더 큰 몫을 차지합니다. 주간 한도, 가격, 이용할 수 있는 모델은 그대로입니다.

[Anthropic 요금 페이지](https://claude.com/pricing)에 따르면 Claude는 사용량을 두 단계로 측정합니다. 모든 플랜에는 5시간 단위로 초기화되는 세션 한도가 있고, 유료 플랜에는 그 위에 주간 한도가 더해집니다. 피크 시간대는 첫 번째 단계에만 영향을 줍니다.

[The Register의 2026년 3월 26일 보도](https://www.theregister.com/2026/03/26/anthropic_tweaks_usage_limits/)에 따르면, 변경을 발표할 때 Anthropic의 Thariq Shihipar는 전체 주간 한도는 그대로이고 한 주 동안의 배분만 바뀐다고 말했습니다. 그는 사용자의 약 7%가 이전에는 닿지 않던 세션 한도에 도달할 것이며, 특히 Pro에서 그럴 것이라고 추정했습니다.

Anthropic은 피크 시간대의 소진 속도나 5시간 세션에 담기는 토큰 양을 한 번도 공개한 적이 없습니다. 온라인에서 정확한 ‘피크 배수’를 인용하는 글을 보더라도 추정치로 받아들이세요.

## Claude 피크 시간대는 언제 시작됐고, 그 뒤 무엇이 바뀌었을까?

Claude 피크 시간대는 2주간의 비피크 프로모션 마지막 날인 2026년 3월 27일부터 적용됐습니다. 그 뒤 Anthropic은 Claude Code에 대한 영구 제외를 하나 추가했고, 별도의 한도 상향을 여러 차례 진행했습니다.

- **2026년 3월 13–27일:** [비피크 2배 프로모션](/deals/claude-march-2026-offpeak-2x/)이 Free, Pro, Max, Team을 대상으로 평일 미국 동부 시간(ET) 오전 8시–오후 2시 외 시간과 주말 내내 세션 한도를 두 배로 늘렸습니다. 이 프로모션은 종료됐습니다.
- **2026년 3월 27일:** [피크 시간대가 적용됐습니다](/deals/claude-peak-hours-introduced/). 이제 평일 13:00–19:00 UTC에는 세션 한도가 더 빨리 소진됩니다.
- **2026년 5월 6일:** Anthropic은 [공식 발표](https://www.anthropic.com/news/higher-limits-spacex)를 통해 [Claude Code의 5시간 한도를 두 배로 늘리고 Pro와 Max의 Claude Code에 적용되던 피크 시간대 한도 감소를 없앴습니다](/deals/claude-code-5h-limits-doubled/).
- **2026년 10월 1–15일:** [아티팩트 사용 프로모션](/deals/claude-artifact-usage-promo-oct-2026/)으로 Pro, Max, Team에서는 아티팩트를 만들거나 편집한 뒤 보내는 다음 채팅 메시지 10개가 5시간 한도에 50% 적게 반영됩니다. 2026년 10월 4일 현재 진행 중이며, 10월 15일 오후 11시 59분(PT)까지 이어집니다.

올해의 다른 세션·주간 한도 변경은 모두 [Claude 사용 한도 가이드](/blog/claude-usage-limits/)에서 확인하세요.

## 피크 시간대의 영향을 받는 Claude 플랜은?

Free, Pro, Max, Team 플랜은 Claude 피크 시간대의 영향을 받고, Enterprise 플랜은 받지 않습니다. Pro와 Max의 Claude Code는 적용 대상에서 제외됩니다.

| 플랜 | 채팅, 데스크톱, 모바일, Cowork | Claude Code |
|---|---|---|
| Free | 적용 | Free에는 미포함 |
| Pro | 적용 | 2026년 5월 6일부터 제외 |
| Max 5x, Max 20x | 적용 | 2026년 5월 6일부터 제외 |
| Team | 적용 | 제외 발표 없음 |
| Enterprise | 미적용 | 미적용 |

Claude Code 제외는 생각보다 범위가 좁습니다. 같은 Pro나 Max 계정이라도 15:00 UTC에 하는 긴 채팅은 여전히 세션 한도를 더 빨리 소진하지만, 같은 시각에 실행한 Claude Code 작업은 그렇지 않습니다.

업그레이드해도 피크 시간대는 사라지지 않습니다. [Anthropic의 Max 플랜 도움말](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)에 따르면 Max 5x(월 $100)와 Max 20x(월 $200)는 세션당 Pro의 5배 또는 20배 사용량을 제공하지만, Max의 채팅도 피크 시간대를 똑같이 따릅니다. 더 큰 플랜이 언제 값어치를 하는지는 [Claude Pro vs Max 비교](/blog/claude-pro-vs-max/)에서, 현재 가격은 [Claude 도구 페이지](/tools/claude/)에서 확인하세요.

## Claude 피크 시간대, 현지 시간으로는 몇 시일까?

Claude 피크 시간대는 13:00–19:00 UTC로, 올가을 서머타임이 끝나기 전까지 뉴욕에서는 09:00–15:00, 런던에서는 14:00–20:00입니다.

| 도시 | 현재(서머타임) | 서머타임 종료 후 |
|---|---|---|
| 뉴욕 | 09:00–15:00 EDT | 08:00–14:00 EST(11월 1일부터) |
| 샌프란시스코 | 06:00–12:00 PDT | 05:00–11:00 PST(11월 1일부터) |
| 런던 | 14:00–20:00 BST | 13:00–19:00 GMT(10월 25일부터) |
| 파리 / 베를린 | 15:00–21:00 CEST | 14:00–20:00 CET(10월 25일부터) |
| 이스탄불 | 16:00–22:00 | 변동 없음(UTC+3) |
| 뉴델리 | 18:30–00:30 IST | 변동 없음 |
| 베이징 | 21:00–03:00 CST | 변동 없음 |
| 도쿄 / 서울 | 22:00–04:00 | 변동 없음 |
| 상파울루 | 10:00–16:00 | 변동 없음(UTC−3) |

EU는 2026년 10월 25일, 미국은 2026년 11월 1일에 서머타임이 끝나 시계를 한 시간 되돌립니다. UTC 기준 시간대는 그대로이므로 이 지역들의 현지 피크 시간대는 한 시간씩 앞당겨집니다.

많은 사람이 헷갈리는 부분이 두 가지 있습니다.

- **늦은 밤의 피크 시간대는 자정을 넘깁니다.** 뉴델리, 베이징, 도쿄, 서울에서는 금요일 피크 시간대가 현지 시간 토요일 새벽에 끝납니다. 도쿄의 토요일 00:00–04:00도 피크로 계산됩니다.
- **처음 발표된 문구는 두 가지였습니다.** The Register에 따르면 발표문은 피크 시간대를 오전 5–11시(PT)와 오후 1–7시(GMT)로 안내했습니다. 두 표현은 캘리포니아가 표준시를 쓸 때만 일치하며, 2026년 11월 1일까지는 오전 5시(PDT)가 12:00 UTC입니다. PromoClock은 13:00–19:00 UTC를 기준으로 합니다. 미국 서부에 있고 여유를 두고 싶다면, 두 표현이 다시 일치하는 11월 1일까지는 05:00–12:00 PDT를 피크로 보세요.

## 13:00–19:00 UTC는 지금도 공식 기준일까?

이 시간대는 2026년 3월 공식 발표됐지만, 현재 Anthropic 고객센터에는 더 이상 명시돼 있지 않습니다. 2026년 10월 기준 PromoClock이 확인한 Max 플랜, 사용 한도 모범 사례, 사용 크레딧에 관한 고객센터 문서는 5시간 세션과 주간 한도를 설명할 뿐 피크 시간대는 언급하지 않습니다.

PromoClock은 이 공백을 다음과 같이 처리합니다.

- 마지막으로 공식 안내된 시간대인 평일 13:00–19:00 UTC를 시계, API, 이 가이드에 계속 표시합니다.
- 현재 정책 문구인 것처럼 내세우지 않고, 고객센터에는 더 이상 나오지 않는다는 사실을 분명히 밝힙니다.
- 한도가 바뀔 때마다 Anthropic 고객센터, 블로그, 직원 공지를 확인하며, Anthropic이 새 시간대나 종료일을 발표하면 시계, API, 이 가이드를 업데이트합니다.

출처와 날짜를 확인하는 방법은 [소개 페이지](/about/)에서 설명합니다.

## 오늘 Claude가 피크 시간대인지 확인하려면?

[PromoClock 홈페이지](/)를 여세요. 실시간 시계가 오늘 Claude가 피크인지 비피크인지, 현지 시간 기준 피크 시간대, 다음 전환까지의 카운트다운을 보여 줍니다. 개발자는 같은 상태를 JSON으로 조회할 수 있습니다.

![비피크 상태의 Claude, 다음 전환까지의 카운트다운, 현지 시간 기준 다음 피크 시간대를 보여 주는 PromoClock의 Claude Watch](../images/claude-watch-peak-hours.jpg)

엔드포인트는 `GET https://promoclock.co/api/status`입니다. 무료이고 CORS를 지원하며 IP당 분당 60회까지 요청할 수 있고, PromoClock의 유일한 공개 API입니다. 응답에는 다음 항목이 포함됩니다.

- `status`: `peak` 또는 `off_peak`, 그리고 불리언 값 `isPeak`.
- `nextChange`: ISO 8601 타임스탬프 형식의 다음 전환 시각, 그리고 `minutesUntilChange`.
- `label`: 사람이 읽기 쉬운 짧은 상태 문구.

```bash
curl -s https://promoclock.co/api/status
```

홈페이지의 [개발자 도구 섹션](/#developer-tools)에는 바로 복사해 쓸 수 있는 curl·zsh 스니펫이 있으며, 셸 프롬프트에 빨간색 또는 초록색 점을 띄우는 스니펫도 있습니다. Slack이나 Discord 봇이 1분마다 엔드포인트를 조회하다가 `status`가 바뀌면 알림을 올리게 할 수도 있습니다.

Anthropic의 [사용 한도 모범 사례](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)에 따르면, Claude 안에서는 Settings > Usage에서 내 세션 한도와 주간 한도를 얼마나 썼는지 확인할 수 있습니다.

## 피크 시간대를 피해 무거운 작업을 배치하려면?

가장 무거운 Claude 작업은 평일 13:00–19:00 UTC 밖으로 옮기고, 피크 시간대에는 짧은 질문만 하세요. 주말은 어디서나 비피크입니다.

Anthropic은 작업을 무겁게 만드는 요인으로 메시지 길이, 첨부 파일 크기, 대화 길이, Research와 웹 검색 같은 도구, 모델 선택, effort 수준, 아티팩트, 코드 실행이나 웹 탐색 같은 다단계 작업을 꼽습니다. 바로 이런 작업을 옮기면 됩니다.

지역별로 보면 다음과 같습니다.

- **미국 동부:** 피크는 09:00–15:00 EDT입니다. 무거운 작업은 09:00 전이나 15:00 이후에 시작하고, 2026년 11월 1일부터는 EST 기준 08:00 전이나 14:00 이후에 시작하세요.
- **미국 서부:** 피크가 06:00–12:00 PDT이므로 오후와 저녁은 비피크입니다.
- **유럽과 튀르키예:** 피크가 오후와 이른 저녁에 걸칩니다. 긴 문서와 Research는 오전에 하는 것이 가장 좋습니다.
- **인도:** 피크가 18:30–00:30 IST이므로 업무 시간은 비피크입니다.
- **중국, 일본, 한국:** 피크가 늦은 밤이므로 업무 시간 전체가 비피크입니다.
- **브라질:** 상파울루 기준 피크는 10:00–16:00입니다. 무거운 작업은 이른 아침과 저녁에 하세요.

Pro나 Max라면 피크 시간대에는 순서를 뒤집으세요. 적용 대상에서 제외된 Claude Code 작업을 돌리고, 긴 채팅은 나중으로 미루면 됩니다. 피크 시간대 도중 세션 한도에 걸리면 5시간 세션이 초기화될 때 풀립니다.

## 결론: 피크 시간대에 어떻게 대응할까?

Claude 피크 시간대에 깎이는 것은 세션 한도이지, 주간 한도가 아닙니다. PromoClock의 추천은 다음과 같습니다.

- **가볍게 쓰는 Free·Pro 사용자:** 피크 시간대는 대부분 신경 쓰지 않아도 됩니다. 피크 중에 한도에 걸리면 5시간 초기화를 기다리세요.
- **유럽, 튀르키예, 브라질의 헤비 채팅 사용자:** 긴 문서와 Research는 피크가 시작되기 전인 오전에 하세요.
- **미국 사용자:** 큰 작업은 동부에서는 이른 아침에, 서부에서는 오후에 하고, 11월 1일 이후에는 시간을 다시 확인하세요.
- **Pro·Max를 쓰는 개발자:** 피크 시간대에는 Claude Code를 쓰고, 긴 채팅은 비피크에 하세요.
- **Team 관리자:** Anthropic이 Team의 Claude Code 제외를 발표하지 않았으므로 일괄 작업은 비피크로 잡으세요.

긴 세션을 시작하기 전에 [Claude Watch](/)를 확인하세요. 지금 어떤 상태인지 가장 빨리 알 수 있습니다.
