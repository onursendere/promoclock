Claudeのピーク時間帯は平日の13:00〜19:00 UTCです。この6時間は、Free、Pro、Max、Teamプランの5時間のセッション上限の消費が通常より早くなりますが、週間上限は変わりません。平日の夕方から夜、深夜、そして週末は終日オフピークです。このガイドでは、2026年10月時点のルール、9都市での時間帯、重い作業をピーク時間帯からずらすシンプルな計画を紹介します。

## Claudeのピーク時間帯とは？

Claudeのピーク時間帯とは、平日の決まった時間帯（13:00〜19:00 UTC）のことで、この間はAnthropicが5時間のセッションの利用枠を早く減らしています。この時間帯は2026年3月27日から適用されています。

- **ピーク**：月曜〜金曜の13:00〜19:00 UTC。
- **オフピーク**：平日のそれ以外の時間と、土曜・日曜の終日（UTC）。
- **終了日**：発表なし。Anthropicは、この時間帯をいつ撤廃するのか、そもそも撤廃するのかを明らかにしていません。

PromoClockのトップページ[Claude Watch](/)では、この時間帯をリアルタイムで追跡しています。Claudeが今ピーク時間帯かどうか、現地時間でのピーク時間帯、次の切り替わりまでのカウントダウンを表示します。

## Claudeのピーク時間帯に何が変わる？

変わるのは5時間のセッション上限の消費ペースだけです。ピーク時間帯には、同じ作業でもセッションの利用枠をより多く使います。週間上限、料金、使えるモデルは変わりません。

Claudeの使用量は2段階で計測されます。[Anthropicの料金ページ](https://claude.com/pricing)によると、すべてのプランに5時間のローリングウィンドウでリセットされるセッション上限があり、有料プランにはさらに週間上限が加わります。ピーク時間帯が影響するのは1段階目だけです。

[The Registerの2026年3月26日の報道](https://www.theregister.com/2026/03/26/anthropic_tweaks_usage_limits/)によると、変更の発表時、AnthropicのThariq Shihipar氏は、週全体の上限は変わらず、週の中での配分が変わるだけだと説明しました。同氏は、これまで達しなかったセッション上限に達するユーザーは約7%で、特にProで多いと見積もっていました。

Anthropicは、ピーク時間帯の消費ペースも、5時間のセッションに何トークン含まれるかも公表していません。ネット上で見かける正確な「ピーク倍率」は、推測にすぎないと考えてください。

## Claudeのピーク時間帯はいつから？これまでの変更点

Claudeのピーク時間帯は2026年3月27日に始まりました。2週間にわたるオフピークのキャンペーンの最終日です。それ以降、AnthropicはClaude Codeを恒久的に対象外とし、別途いくつかの上限引き上げを実施しています。

- **2026年3月13日〜27日**：[オフピーク2倍キャンペーン](/deals/claude-march-2026-offpeak-2x/)で、Free、Pro、Max、Teamを対象に、平日の米国東部時間（ET）8:00〜14:00以外と週末終日のセッション上限が2倍になりました。すでに終了しています。
- **2026年3月27日**：[ピーク時間帯の適用が始まりました](/deals/claude-peak-hours-introduced/)。現在は平日の13:00〜19:00 UTCに、セッション上限の消費が早くなります。
- **2026年5月6日**：Anthropicの[公式発表](https://www.anthropic.com/news/higher-limits-spacex)によると、[Claude Codeの5時間上限が2倍になり、ProとMaxのClaude Codeはピーク時間帯の上限削減の対象外になりました](/deals/claude-code-5h-limits-doubled/)。
- **2026年10月1日〜15日**：[アーティファクト使用量キャンペーン](/deals/claude-artifact-usage-promo-oct-2026/)により、Pro、Max、Teamでは、アーティファクトを作成・編集した後の10件のチャットメッセージが、5時間上限に対して50%少なくカウントされます。2026年10月4日時点で実施中で、太平洋時間（PT）10月15日午後11時59分まで続きます。

今年のそのほかのセッション上限・週間上限の変更については、[Claudeの利用上限](/blog/claude-usage-limits/)のガイドをご覧ください。

## ピーク時間帯の影響を受けるClaudeのプランは？

ピーク時間帯の影響を受けるのはFree、Pro、Max、Teamプランで、Enterpriseプランは対象外です。ProとMaxのClaude Codeも対象外です。

| プラン | チャット、デスクトップ、モバイル、Cowork | Claude Code |
|---|---|---|
| Free | 対象 | Freeには含まれない |
| Pro | 対象 | 2026年5月6日から対象外 |
| Max 5xとMax 20x | 対象 | 2026年5月6日から対象外 |
| Team | 対象 | 対象外の発表なし |
| Enterprise | 対象外 | 対象外 |

Claude Codeの対象外は、聞こえるほど範囲が広くありません。同じProやMaxのアカウントでも、15:00 UTCの長いチャットはセッションを早く消費しますが、同じ時刻のClaude Codeの実行は影響を受けません。

アップグレードしてもピーク時間帯はなくなりません。[AnthropicのMaxプランの記事](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)によると、Max 5x（月額$100）とMax 20x（月額$200）はセッションあたりProの5倍または20倍の使用量を提供しますが、Maxのチャットもピーク時間帯に従います。上位プランが見合うかどうかは[Claude ProとMaxの比較](/blog/claude-pro-vs-max/)で、現在の料金は[Claudeのツールページ](/tools/claude/)で確認できます。

## Claudeのピーク時間帯は日本時間で何時？

Claudeのピーク時間帯は13:00〜19:00 UTCで、日本時間では22:00〜翌04:00です。ニューヨークでは09:00〜15:00、ロンドンでは14:00〜20:00で、こちらはこの秋の時刻変更までの時間です。

| 都市 | 現在（夏時間） | 時刻変更後 |
|---|---|---|
| ニューヨーク | 09:00〜15:00 EDT | 08:00〜14:00 EST（11月1日から） |
| サンフランシスコ | 06:00〜12:00 PDT | 05:00〜11:00 PST（11月1日から） |
| ロンドン | 14:00〜20:00 BST | 13:00〜19:00 GMT（10月25日から） |
| パリ／ベルリン | 15:00〜21:00 CEST | 14:00〜20:00 CET（10月25日から） |
| イスタンブール | 16:00〜22:00 | 変更なし（UTC+3） |
| ニューデリー | 18:30〜翌00:30 IST | 変更なし |
| 北京 | 21:00〜翌03:00 CST | 変更なし |
| 東京／ソウル | 22:00〜翌04:00 | 変更なし |
| サンパウロ | 10:00〜16:00 | 変更なし（UTC−3） |

EUは2026年10月25日、米国は2026年11月1日に時計を1時間戻します。UTCの時間帯は変わらないため、これらの地域では現地時間のピーク時間帯が1時間早まります。

見落としやすい点が2つあります。

- **深夜の時間帯は日付をまたぎます**。ニューデリー、北京、東京、ソウルでは、金曜の時間帯が現地時間の土曜早朝に終わります。東京の土曜00:00〜04:00も、ピーク時間帯に含まれます。
- **当初の発表には2通りの表記がありました**。The Registerによると、発表では時間帯が「太平洋時間（PT）の午前5時〜11時」と「GMTの午後1時〜7時」の2通りで示されていました。この2つが一致するのはカリフォルニアが標準時の間だけで、2026年11月1日まではPDTの午前5時は12:00 UTCです。PromoClockでは13:00〜19:00 UTCを採用しています。米国西海岸にいて余裕を持たせたい場合は、2つの表記が再び一致する11月1日まで、05:00〜12:00 PDTをピーク時間帯とみなしてください。

## 13:00〜19:00 UTCは今も公式の時間帯？

この時間帯は2026年3月に公式に発表されましたが、現在のAnthropicのヘルプセンターには明記されていません。2026年10月時点で、私たちが確認したMaxプラン、使用量のベストプラクティス、利用クレジットに関するヘルプセンターの記事は、5時間のセッションと週間上限を説明しているものの、ピーク時間帯には触れていません。

PromoClockは、このギャップに次のように対応しています。

- 最後に公式に説明された時間帯（平日の13:00〜19:00 UTC）を、時計、API、このガイドで引き続き表示します。
- 現行のポリシーの文言として示すのではなく、ヘルプセンターにはもう記載がないことをはっきり伝えます。
- 上限が変わるたびにAnthropicのヘルプセンター、ブログ、社員の発表を確認し、新しい時間帯や終了日が発表されれば、時計、API、このガイドを更新します。

出典と日付の確認方法は、[サイトについて](/about/)のページで説明しています。

## Claudeが今ピーク時間帯か確認するには？

[PromoClockのトップページ](/)を開いてください。ライブ時計に、今日のClaudeがピーク時間帯かオフピークか、現地時間でのピーク時間帯、次の切り替わりまでのカウントダウンが表示されます。開発者は同じステータスをJSONで取得できます。

![PromoClockのClaude Watch。Claudeがオフピークであること、次の切り替わりまでのカウントダウン、現地時間での次のピーク時間帯を表示している画面](../images/claude-watch-peak-hours.jpg)

エンドポイントは`GET https://promoclock.co/api/status`です。無料でCORSに対応し、IPごとに毎分60リクエストまで利用できます。PromoClockで唯一の公開APIです。レスポンスには次の項目が含まれます。

- `status`：`peak`または`off_peak`と、真偽値の`isPeak`。
- `nextChange`：次の切り替わりを示すISO 8601形式のタイムスタンプと、`minutesUntilChange`。
- `label`：人が読みやすい短いステータス文。

```bash
curl -s https://promoclock.co/api/status
```

トップページの[開発者向けツール](/#developer-tools)には、そのまま使えるcurlとzshのスニペットがあり、シェルのプロンプトに赤か緑のドットを表示するものも含まれます。SlackやDiscordのボットで1分に1回エンドポイントを呼び出し、`status`が切り替わったら投稿することもできます。

Claude内では、設定画面のSettings > Usageで、自分のセッション上限と週間上限をどれだけ使ったかを確認できます。Anthropicの[使用量のベストプラクティス](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)に記載されている方法です。

## ピーク時間帯を避けてClaudeの重い作業をするには？

Claudeで最も重い作業は平日の13:00〜19:00 UTC以外に移し、ピーク時間帯は短い質問に使いましょう。週末はどの地域でもオフピークです。

Anthropicは、タスクを重くする要因として、メッセージの長さ、添付ファイルのサイズ、会話の長さ、ResearchやWeb検索などのツール、モデルの選択、effortレベル、アーティファクト、コードの実行やブラウジングのような複数ステップのタスクを挙げています。移すべきなのはこうした作業です。

地域別に見ると、次のとおりです。

- **米国東海岸**：ピーク時間帯は09:00〜15:00 EDTです。重い作業は09:00より前か15:00以降に始めましょう。2026年11月1日からは、08:00より前か14:00以降（EST）です。
- **米国西海岸**：ピーク時間帯は06:00〜12:00 PDTなので、午後と夜はオフピークです。
- **ヨーロッパとトルコ**：ピーク時間帯は午後から夕方にかかります。長い文書やResearchには午前中が最適です。
- **インド**：ピーク時間帯は18:30〜翌00:30 ISTなので、日中の勤務時間はオフピークです。
- **中国、日本、韓国**：ピーク時間帯は深夜にあたるため、日中の勤務時間はまるごとオフピークです。
- **ブラジル**：サンパウロのピーク時間帯は10:00〜16:00です。重い作業は早朝と夜に回しましょう。

ProやMaxなら、ピーク時間帯は順番を入れ替えましょう。対象外のClaude Codeのタスクを実行し、長いチャットは後に回します。ピーク時間帯の途中でセッション上限に達しても、5時間のウィンドウがリセットされれば上限は解除されます。

## まとめ：Claudeのピーク時間帯との付き合い方

Claudeのピーク時間帯で減るのはセッションの利用枠で、週間の利用枠は減りません。おすすめは次のとおりです。

- **FreeやProのライトユーザー**：ピーク時間帯はほとんど気にしなくて大丈夫です。ピーク時間帯に上限に達したら、5時間のリセットを待ちましょう。
- **ヨーロッパ、トルコ、ブラジルでチャットを多用する人**：長い文書やResearchは、ピーク時間帯が始まる前の午前中に回しましょう。
- **米国のユーザー**：大きな作業は東海岸なら早朝、西海岸なら午後に行い、11月1日以降は時間を確認し直しましょう。
- **ProやMaxを使う開発者**：ピーク時間帯はClaude Codeに使い、長いチャットはオフピークに回しましょう。
- **Teamの管理者**：AnthropicはTeamのClaude Codeを対象外にすると発表していないため、バッチ作業はオフピークに予定しましょう。

長いセッションの前には[Claude Watch](/)を確認しましょう。今の状況を知る一番早い方法です。
