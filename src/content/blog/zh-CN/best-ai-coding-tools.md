## 你需要哪种AI编程工具？

先选类型，再选品牌：AI在哪里工作，比它跑的是哪个模型更重要。现在大多数工具可以分成5类。

- **终端智能体**（Claude Code、Codex CLI、Warp）在命令行中读取你的代码仓库、运行命令并编辑文件。你在git中审查diff。
- **AI代码编辑器**（Cursor、Devin Desktop、Kiro）用一款围绕智能体打造的编辑器取代你现在的编辑器。Devin Desktop兼容VS Code设置，Kiro基于Code OSS构建。
- **IDE扩展**（GitHub Copilot、Cline、JetBrains AI）接入你已经在用的编辑器。
- **自主智能体**（Devin，以及Copilot、Codex、Cursor和Kiro的云端模式）接收一张工单，在远程机器上工作，然后提交拉取请求。
- **应用构建工具**（Replit、Lovable、Bolt.new、v0、Base44）把一句提示词变成托管好的应用，适合不写代码的人。

计费方式也不一样：Claude Code与Claude聊天共用一个用量池，Copilot消耗每个价值$0.01的AI Credits，Kiro和Warp出售积分，Cline则按你自己的API费率直接转嫁模型成本。

## 哪些终端编程智能体值得付费？

终端优先的开发者，我们推荐Claude Code；如果你已经在为ChatGPT付费，Codex更划算；想换一个新终端的人适合Warp。

### Claude Code

Claude Code是Anthropic的智能体编程工具，可在终端、VS Code、JetBrains IDE和Claude桌面应用中使用。根据[Anthropic的定价页面](https://claude.com/pricing)，它包含在每个付费套餐中：Pro为$20/月（$200/年），Max 5x为$100/月，Max 20x为$200/月。Claude Free不包含它。

Claude Code与Claude聊天共用一个用量池，按滚动5小时会话加每周上限计量。2026年5月6日，Anthropic[把Claude Code的5小时额度翻倍](/deals/claude-code-5h-limits-doubled/)，并让Pro和Max上的Claude Code不再受工作日高峰时段的影响。自9月14日起，它的每周额度[永久提高25%](/deals/claude-code-weekly-plus25-permanent/)。正如我们的[高峰时段实时时钟](/)所示，Claude聊天在工作日13:00–19:00 UTC仍会消耗得更快；详情见[Claude用量额度指南](/blog/claude-usage-limits/)。

9月23日订阅有效的个人Pro和Max订阅者，可在2026年10月7日前领取[$100或$250的Claude Code云会话积分](/deals/claude-code-cloud-credit-2026/)。适合：覆盖整个代码仓库的智能体工作。

### OpenAI Codex

OpenAI Codex包含在每个ChatGPT套餐中：Free（$0）、Go（$8/月）、Plus（$20/月）和Pro（$100、$200或$500/月）。它以CLI以及VS Code、Cursor和Windsurf扩展的形式运行，也能在ChatGPT桌面和网页应用、iOS以及云端沙箱中使用。

Codex的额度只是估算。OpenAI估计，在Plus上每个5小时窗口内，最强的Codex模型可处理10–100条本地消息，最轻量的模型可处理250–2,000条，与ChatGPT Work共用。适合：已经在为ChatGPT付费的开发者。

### Warp

Warp是一款内置编程智能体的终端，自2026年4月28日起，其客户端以AGPL协议开源。Warp Free包含终端和Agent CLI，但不含AI用量，需要你自带API密钥。Build为$20/月，含1,500积分；Max为$200/月，含18,000积分。适合：DevOps和重度使用终端的工程师。

## 该换用哪款AI代码编辑器？

只想用一款AI编辑器的专业开发者，我们推荐Cursor；同时管理多个智能体的人适合Devin Desktop，想先写规格的团队适合Kiro。

### Cursor

Cursor Hobby免费，无需信用卡，Agent请求次数有限。根据[Cursor的定价页面](https://cursor.com/pricing)，Pro为$20/月，Pro+为$60/月（Agent额度为Pro的3倍），Ultra为$200/月（20倍）；按年付费可省20%。

Cursor自研的Grok和Composer模型使用更大的内置用量池，Claude、GPT和Gemini则按API费率计费。Cursor的文档估计，每天使用智能体的用户总用量花费约为每月$60–$100，所以预算要超出$20。适合：整天运行智能体的专业开发者。

### Devin Desktop（原Windsurf）

Windsurf在2026年6月2日通过一次更新变成了Devin Desktop，编辑器、扩展、设置和价格都保持不变。Devin Desktop Free包含少量配额和无限次Tab补全；Pro为$20/月，Max为$200/月，Teams起价$80/月，每个完整席位另加$40。2026年10月16日前，[Pro和Max可免费使用SWE-2](/deals/windsurf-swe-2-free-oct-2026/)。适合：在一个面板上管理本地和云端智能体的开发者。

### Kiro

Kiro是AWS推出的规格驱动IDE：在智能体写代码之前，提示词会先变成需求、设计和任务清单。Kiro Free每月包含50积分；Pro为$20/月，含1,000积分，Pro+为$40，含2,000积分，Pro Max为$100，含5,000积分，Power为$200，含10,000积分。适合：希望AI写的代码背后有文档化意图的团队。

## 有哪些AI助手能接入你现在用的IDE？

VS Code和大多数编辑器的默认选择是GitHub Copilot；自带密钥的用户适合Cline，IntelliJ、PyCharm和Kotlin开发者适合JetBrains AI。

### GitHub Copilot

Copilot Free为$0，每月2,000次代码补全，聊天和智能体使用有限。根据[GitHub的套餐页面](https://github.com/features/copilot/plans)，Pro为$10/月，每月含$15的AI Credits；Pro+为$39，含$70；Max为$100，含$200。自2026年6月1日起，聊天、智能体和代码审查都会消耗AI Credits，而付费套餐上的补全依然不限次数。

Copilot可在VS Code、Visual Studio、JetBrains IDE、Xcode、Eclipse、Neovim和Zed中使用，还支持github.com、CLI和桌面应用。适合：使用GitHub的团队和注重预算的开发者。

### Cline

Cline是一款免费开源（Apache 2.0）的智能体，支持VS Code、抢先体验中的JetBrains IDE、终端和桌面测试版。你只需为模型付费：可以用自己的API密钥，可以用Cline按成本价提供的推理服务，也可以用$9.99/月的ClinePass使用开放权重模型。Cline在每次编辑或执行命令前都会征求你的同意。适合：想完全自选模型或使用本地模型的开发者。

### JetBrains AI

JetBrains AI在JetBrains IDE中提供补全、聊天和Junie智能体，还能运行Claude Agent、Codex和Gemini CLI。AI Free包含无限次补全和每30天3个AI Credits；AI Pro为$10/月，含10个积分，AI Ultimate为$30/月，含35个积分，每个积分$1。All Products Pack订阅者可免费获得AI Pro。适合：Java、Kotlin和Python开发者。

## 你需要Devin这样的自主智能体吗？

只有当你想把整张工单交出去时才需要：Devin在自己的云端机器上工作并提交拉取请求，不过现在很多编程工具都带有类似的云端智能体。

### Devin

Devin是Cognition推出的云端软件工程师，一个套餐覆盖Devin Cloud、Devin Desktop和Devin CLI。根据[Devin的定价页面](https://devin.ai/pricing)，Free提供少量配额，不含云端智能体；$20/月的Pro增加Devin Cloud；$200/月的Max提高配额。团队可以从Slack、Microsoft Teams、Linear或Jira分配任务。适合：积压了迁移任务和缺陷的团队。

先看看你手上已经有什么：Copilot的云端智能体可以处理GitHub issue，Codex cloud在隔离环境中运行任务，Cursor的云端智能体会开出拉取请求，Kiro Web则在Kiro付费套餐上运行智能体。

## 不会写代码，用哪个AI应用构建工具？

非技术背景的创业者，我们推荐Lovable；想把托管和移动应用放在一个地方的人适合Replit；Bolt.new、v0和Base44覆盖更细分的需求。

### Replit

Replit Starter免费，提供每日Agent积分和1个已发布应用，该应用30天后下线。Core为$20/月（按年付费$18），含$20积分；Pro为$100/月，含$100积分。自2026年8月18日起，Free Mode让Core和Pro订阅者可以在更轻量的模型上完成日常Agent工作，不消耗积分。适合：构建并托管网页和原生移动应用。

### Lovable

Lovable Free每天提供5个构建积分，每月上限30个；Pro起价$25/月，Business起价$50/月。2026年10月31日前，[在每日额度内使用Lovable聊天不消耗积分](/deals/lovable-free-daily-chat-2026/)。适合：没有开发者也要上线全栈网页应用的创业者。

### Bolt.new

Bolt.new Free每月包含1M token，每日上限300K；Pro起价$25/月，含10M token。2026年10月14日前，[Bolt Forge预览](/deals/bolt-forge-preview-2026/)让Pro免费获得最多50倍的Forge用量，$9/月、仅含Forge的Lite套餐仍开放注册。适合：网页和Expo移动应用。

### v0

v0是Vercel面向React和Next.js应用的智能体。新的v0 Free账户可获得一次性$5额度，每天7条消息；Plus为每用户每月$30，Business为$100，与Vercel托管分开计费。适合：在Vercel上做原型。

### Base44

Base44归Wix所有，Free套餐每月包含25个消息积分，最多5个应用。Starter为$20/月（按年付费$16），Builder为$50，Pro为$100，Elite起价$200，Builder及以上支持导出代码。适合：内部工具和客户门户。
