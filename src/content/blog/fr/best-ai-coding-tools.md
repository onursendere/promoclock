## De quel type d’outil IA pour coder avez-vous besoin ?

Choisissez le type avant la marque : l’endroit où l’IA travaille compte plus que le modèle qu’elle utilise. La plupart des outils se répartissent désormais en 5 groupes.

- **Agents en terminal** (Claude Code, Codex CLI, Warp) : ils lisent votre dépôt, lancent des commandes et modifient des fichiers depuis le shell. Vous relisez le diff dans git.
- **Éditeurs de code IA** (Cursor, Devin Desktop, Kiro) : ils remplacent votre éditeur par un éditeur conçu autour des agents. Devin Desktop reste compatible avec les réglages de VS Code, et Kiro repose sur Code OSS.
- **Extensions d’IDE** (GitHub Copilot, Cline, JetBrains AI) : elles se branchent sur l’éditeur que vous utilisez déjà.
- **Agents autonomes** (Devin, ainsi que les modes cloud de Copilot, Codex, Cursor et Kiro) : ils prennent un ticket, travaillent sur une machine distante et renvoient une pull request.
- **Créateurs d’applications** (Replit, Lovable, Bolt.new, v0, Base44) : ils transforment un prompt en application hébergée, pour ceux qui ne codent pas.

La facturation diffère aussi : Claude Code partage un même quota d’utilisation avec le chat Claude, Copilot consomme des AI Credits valant $0.01 chacun, Kiro et Warp vendent des crédits, et Cline répercute le coût des modèles à vos propres tarifs d’API.

## Quels agents de code en terminal valent le coup ?

Claude Code est notre choix pour les développeurs qui travaillent d’abord dans le terminal ; Codex offre un meilleur rapport qualité-prix si vous payez déjà ChatGPT, et Warp convient à ceux qui veulent un nouveau terminal.

### Claude Code

Claude Code est l’outil de code agentique d’Anthropic pour le terminal, VS Code, les IDE JetBrains et l’application de bureau Claude. Selon [la page des tarifs d’Anthropic](https://claude.com/pricing), il est inclus dans toutes les formules payantes : Pro à $20/mois ($200/an), Max 5x à $100/mois et Max 20x à $200/mois. Claude Free ne l’inclut pas.

Claude Code partage un même quota avec le chat Claude, mesuré par session glissante de 5 heures, avec un plafond hebdomadaire en plus. Le 6 mai 2026, Anthropic [a doublé les limites de 5 heures de Claude Code](/deals/claude-code-5h-limits-doubled/) et l’a exempté du ralentissement aux heures de pointe en semaine sur Pro et Max. Depuis le 14 septembre, ses limites hebdomadaires sont [définitivement supérieures de 25 %](/deals/claude-code-weekly-plus25-permanent/). Le chat Claude s’épuise toujours plus vite en semaine, de 13 h à 19 h UTC, comme le montre notre [horloge des heures de pointe en direct](/) ; le [guide des limites d’utilisation de Claude](/blog/claude-usage-limits/) donne les détails.

Les abonnés Pro et Max individuels actifs le 23 septembre peuvent obtenir [$100 ou $250 de crédit cloud Claude Code](/deals/claude-code-cloud-credit-2026/) jusqu’au 7 octobre 2026. Idéal pour : le travail d’agent sur tout un dépôt.

### OpenAI Codex

OpenAI Codex est inclus dans toutes les formules ChatGPT : Free ($0), Go ($8/mois), Plus ($20/mois) et Pro ($100, $200 ou $500 par mois). Il fonctionne en CLI, en extension pour VS Code, Cursor et Windsurf, dans les applications ChatGPT de bureau et web, sur iOS et dans des sandbox cloud.

Les limites de Codex sont des estimations. OpenAI estime de 10 à 100 messages locaux avec son modèle Codex le plus puissant, ou de 250 à 2 000 avec le plus léger, par fenêtre de 5 heures sur Plus, partagés avec ChatGPT Work. Idéal pour : les développeurs qui paient déjà ChatGPT.

### Warp

Warp est un terminal doté d’un agent de code intégré, et son client est open source sous licence AGPL depuis le 28 avril 2026. Warp Free inclut le terminal et l’Agent CLI, mais aucune utilisation d’IA incluse : vous apportez votre propre clé API. Build coûte $20/mois avec 1 500 crédits, et Max $200/mois avec 18 000. Idéal pour : les ingénieurs DevOps et les gros utilisateurs du terminal.

## Quel éditeur de code IA adopter ?

Cursor est notre choix pour les développeurs professionnels qui veulent un seul éditeur IA ; Devin Desktop convient à ceux qui jonglent avec de nombreux agents, et Kiro aux équipes qui veulent commencer par les spécifications.

### Cursor

Cursor Hobby est gratuit, sans carte bancaire, avec un nombre limité de requêtes Agent. Selon [la page des tarifs de Cursor](https://cursor.com/pricing), Pro coûte $20/mois, Pro+ $60/mois avec 3 fois les limites d’Agent de Pro, et Ultra $200/mois avec 20 fois ; la facturation annuelle fait économiser 20 %.

Les modèles maison de Cursor, Grok et Composer, puisent dans une réserve incluse plus importante, tandis que Claude, GPT et Gemini sont facturés aux tarifs de l’API. La documentation de Cursor estime que les utilisateurs quotidiens d’agents dépensent $60–$100 par mois en utilisation totale : prévoyez un budget au-delà de $20. Idéal pour : les professionnels qui font tourner des agents toute la journée.

### Devin Desktop (anciennement Windsurf)

Windsurf est devenu Devin Desktop via une mise à jour le 2 juin 2026, en conservant son éditeur, ses extensions, ses réglages et ses prix. Devin Desktop Free inclut un quota léger et des complétions Tab illimitées ; Pro coûte $20/mois, Max $200/mois, et Teams démarre à $80/mois plus $40 par siège complet. Jusqu’au 16 octobre 2026, [SWE-2 est gratuit sur Pro et Max](/deals/windsurf-swe-2-free-oct-2026/). Idéal pour : les développeurs qui supervisent des agents locaux et cloud depuis un seul tableau de bord.

### Kiro

Kiro est l’IDE d’AWS piloté par les spécifications : les prompts deviennent des exigences, une conception et une liste de tâches avant que les agents écrivent le code. Kiro Free inclut 50 crédits par mois ; Pro coûte $20/mois pour 1 000 crédits, Pro+ $40 pour 2 000, Pro Max $100 pour 5 000 et Power $200 pour 10 000. Idéal pour : les équipes qui veulent une intention documentée derrière le code écrit par l’IA.

## Quels assistants IA s’intègrent à l’IDE que vous utilisez déjà ?

GitHub Copilot est le choix par défaut pour VS Code et la plupart des éditeurs ; Cline convient à ceux qui utilisent leurs propres clés API, et JetBrains AI aux développeurs IntelliJ, PyCharm et Kotlin.

### GitHub Copilot

Copilot Free coûte $0, avec 2 000 complétions de code par mois et un usage limité du chat et de l’agent. Selon [la page des formules de GitHub](https://github.com/features/copilot/plans), Pro coûte $10/mois avec $15 d’AI Credits mensuels, Pro+ $39 avec $70 et Max $100 avec $200. Depuis le 1er juin 2026, le chat, les agents et la revue de code consomment des AI Credits, tandis que les complétions restent illimitées sur les formules payantes.

Copilot fonctionne dans VS Code, Visual Studio, les IDE JetBrains, Xcode, Eclipse, Neovim et Zed, ainsi que sur github.com, en CLI et dans une application de bureau. Idéal pour : les équipes sur GitHub et les développeurs attentifs à leur budget.

### Cline

Cline est un agent gratuit et open source (Apache 2.0) pour VS Code, les IDE JetBrains en accès anticipé, le terminal et une version bureau en bêta. Vous ne payez que les modèles, via vos propres clés API, via l’inférence à prix coûtant de Cline ou via ClinePass à $9.99/mois pour les modèles à poids ouverts. Cline demande votre accord avant chaque modification ou commande. Idéal pour : les développeurs qui veulent un choix de modèles complet ou des modèles locaux.

### JetBrains AI

JetBrains AI couvre la complétion, le chat et l’agent Junie dans les IDE JetBrains, et peut aussi faire tourner Claude Agent, Codex et Gemini CLI. AI Free inclut la complétion illimitée et 3 AI Credits par période de 30 jours ; AI Pro coûte $10/mois avec 10 crédits et AI Ultimate $30/mois avec 35, à $1 le crédit. Les abonnés à All Products Pack ont AI Pro inclus. Idéal pour : les développeurs Java, Kotlin et Python.

## Avez-vous besoin d’un agent autonome comme Devin ?

Seulement si vous voulez confier des tickets entiers : Devin travaille sur sa propre machine cloud et renvoie des pull requests, même si de nombreux outils de code incluent désormais des agents cloud similaires.

### Devin

Devin est l’ingénieur logiciel cloud de Cognition, et une seule formule couvre Devin Cloud, Devin Desktop et la CLI Devin. Selon [la page des tarifs de Devin](https://devin.ai/pricing), Free offre un quota léger sans agents cloud, Pro à $20/mois ajoute Devin Cloud, et Max à $200/mois relève les quotas. Les équipes assignent le travail depuis Slack, Microsoft Teams, Linear ou Jira. Idéal pour : les équipes qui ont un arriéré de migrations et de bugs.

Vérifiez d’abord ce que vous avez déjà : l’agent cloud de Copilot travaille à partir des issues GitHub, Codex cloud exécute des tâches dans des environnements isolés, les agents cloud de Cursor ouvrent des pull requests, et Kiro Web fait tourner des agents avec les formules Kiro payantes.

## Quels créateurs d’applications IA fonctionnent sans coder ?

Lovable est notre choix pour les fondateurs non techniques, et Replit pour ceux qui veulent l’hébergement et les applications mobiles au même endroit ; Bolt.new, v0 et Base44 couvrent des besoins plus ciblés.

### Replit

Replit Starter est gratuit, avec des crédits Agent quotidiens et 1 application publiée, qui passe hors ligne au bout de 30 jours. Core coûte $20/mois ($18 en facturation annuelle) avec $20 de crédits, et Pro $100/mois avec $100. Depuis le 18 août 2026, le Free Mode permet aux abonnés Core et Pro d’effectuer le travail courant de l’Agent sur un modèle plus léger sans dépenser de crédits. Idéal pour : créer et héberger des applications web et des applications mobiles natives.

### Lovable

Lovable Free offre 5 crédits de création par jour, plafonnés à 30 par mois ; Pro démarre à $25/mois et Business à $50/mois. Jusqu’au 31 octobre 2026, [le chat de Lovable ne consomme aucun crédit jusqu’à une limite quotidienne](/deals/lovable-free-daily-chat-2026/). Idéal pour : les fondateurs qui lancent des applications web full-stack sans développeur.

### Bolt.new

Bolt.new Free inclut 1M de tokens par mois avec un plafond quotidien de 300K, et Pro démarre à $25/mois avec 10M de tokens. Jusqu’au 14 octobre 2026, la [préversion de Bolt Forge](/deals/bolt-forge-preview-2026/) donne gratuitement à Pro jusqu’à 50 fois plus d’utilisation de Forge, et les inscriptions à la formule Lite à $9/mois, limitée à Forge, restent ouvertes. Idéal pour : les applications web et les applications mobiles Expo.

### v0

v0 est l’agent de Vercel pour les applications React et Next.js. Les nouveaux comptes v0 Free reçoivent un crédit unique de $5 et 7 messages par jour ; Plus coûte $30 par utilisateur et par mois et Business $100, facturés séparément de l’hébergement Vercel. Idéal pour : le prototypage sur Vercel.

### Base44

Base44, propriété de Wix, inclut 25 crédits de messages par mois et jusqu’à 5 applications avec Free. Starter coûte $20/mois ($16 en facturation annuelle), Builder $50, Pro $100 et Elite à partir de $200, avec l’export du code à partir de Builder. Idéal pour : les outils internes et les portails clients.

## Quelles sont les meilleures options gratuites et étudiantes pour coder avec l’IA ?

GitHub Copilot Free et Cursor Hobby sont les meilleurs points de départ gratuits, et les étudiants vérifiés devraient d’abord activer la formule gratuite Copilot Student.

- **Formules gratuites :** Copilot Free, Cursor Hobby, Devin Desktop Free, Codex dans ChatGPT Free, Kiro Free et JetBrains AI Free. Cline et Warp sont gratuits si vous apportez votre propre clé API : vous ne payez alors que votre fournisseur de modèles.
- **Étudiants :** [Copilot Student](/deals/github-copilot-student-plan/) est gratuit pour les étudiants vérifiés via GitHub Education. Kiro donne 1 000 crédits par mois gratuits pendant un an dans les universités éligibles, au nombre de 132 en septembre 2026. Lovable offre 50 % de réduction sur Pro, et Base44 50 % sur Starter ou Builder, pendant 12 mois maximum.
- **Terminé :** l’[année gratuite de Cursor Pro pour les étudiants](/deals/cursor-student-pro-year/) a fermé aux nouvelles inscriptions le 25 juin 2026.

Notre [guide des offres étudiantes sur les outils IA](/blog/ai-student-discounts/) recense toutes les offres étudiantes vérifiées, et notre sélection des [meilleurs outils IA gratuits](/blog/best-free-ai-tools/) couvre les formules gratuites au-delà du code.

- **Développeurs qui travaillent d’abord dans le terminal :** Claude Code avec Claude Pro à $20/mois ; passez à Max 5x à $100/mois si les limites hebdomadaires vous bloquent.
- **Développeurs qui veulent un seul éditeur IA :** Cursor Pro à $20/mois, avec un budget supplémentaire si vous faites tourner des agents tous les jours.
- **Petits budgets et équipes sur GitHub :** GitHub Copilot Pro à $10/mois.
- **Abonnés ChatGPT :** Codex, déjà inclus dans votre formule.
- **Utilisateurs de JetBrains :** JetBrains AI Pro à $10/mois, ou inclus dans All Products Pack.
- **Adeptes de l’open source et de leurs propres clés API :** Cline.
- **Équipes orientées spécifications ou AWS :** Kiro Pro à $20/mois.
- **Équipes qui délèguent des tickets :** Devin Pro à $20/mois.
- **Non-développeurs :** Lovable ou Replit.
- **Étudiants :** d’abord Copilot Student, puis les crédits étudiants de Kiro.
