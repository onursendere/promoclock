## Qu’est-ce que Le Chat (désormais Vibe) ?
Le Chat était l’assistant de Mistral AI ; depuis le 28 mai 2026, il s’appelle Vibe. La même URL et le même identifiant ouvrent un agent unique pour la productivité professionnelle et le code, disponible sur le web, dans les applications iOS et Android, dans VS Code et dans le terminal.

## Points forts
- **Un seul abonnement pour le travail et le code.** Chat, Work et Code partagent une même formule : Pro couvre à la fois l’assistant et l’agent de code.
- **Des étapes visibles.** Vibe affiche chaque appel d’outil et chaque chaîne de raisonnement, et demande votre accord avant les actions sensibles.
- **Teleport.** Une session de code en cours peut passer de votre terminal au cloud, et inversement, en conservant son historique et ses validations.

## Limites
Le changement de nom a réparti les fonctionnalités entre Work et Chat : les anciens guides de Le Chat peuvent ne plus correspondre à l’application, et la documentation produit a migré vers docs.mistral.ai. Free est plafonné en messages, en recherches, en sessions de code et en stockage de documents. Les prix affichés s’entendent hors taxes.
