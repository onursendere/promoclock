## Qu’est-ce que GitHub Copilot ?
GitHub Copilot propose complétions, chat et agents dans VS Code, Visual Studio, les IDE JetBrains, Xcode, Eclipse, Neovim et Zed, sur github.com et GitHub Mobile, ainsi que dans le terminal. L’application de bureau Copilot est disponible avec toutes les formules depuis le 7 juillet 2026.

## Ce qui a changé en 2026
- **Facturation à l’usage.** Le 1er juin 2026, le décompte des requêtes premium a été remplacé par les GitHub AI Credits, facturés selon le tarif par token de chaque modèle.
- **Quotas flexibles et formule Max.** Le 12 mai 2026, GitHub a annoncé une nouvelle formule Max et, pour Pro et Pro+, un quota flexible variable en plus des crédits de base.
- **Pause des inscriptions.** Les formules payantes individuelles ont été fermées aux nouveaux utilisateurs du 20 avril jusqu’à une réouverture progressive à partir du 17 juin 2026.

## Points faibles
Le coût mensuel est difficile à prévoir : une longue session d’agent sur un modèle de pointe consomme bien plus de crédits qu’une question rapide posée à un modèle léger. La part flexible de chaque quota n’est pas fixe. Les utilisateurs Free et Student ne peuvent pas choisir leur modèle manuellement, et les revues de pull requests sur github.com ne font pas partie de Copilot Free.
