## Qu’est-ce que Devin ?
Devin est l’agent de code autonome de Cognition, destiné aux équipes d’ingénierie aux projets complexes et multi-dépôts. Il apprend les conventions d’une base de code, mène les tâches sur sa propre machine et renvoie des pull requests pour relecture.

## Un produit, plusieurs surfaces
Cognition a fusionné ses deux produits en 2026. Windsurf.com redirige désormais vers Devin Desktop, un IDE complet compatible avec les réglages Windsurf et VS Code, qui s’ouvre sur un gestionnaire d’agents. Devin Cloud gère à distance le travail de longue durée, Devin CLI tourne dans le terminal, et Devin Review couvre la revue de code. Un même quota d’abonnement est partagé entre les sessions Devin, la CLI et Devin Desktop.

## Limites
- Les agents cloud ne sont pas inclus dans la formule gratuite.
- Les quotas ne sont pas publiés en chiffres fixes ; le coût par message dépend du modèle, de la taille de la tâche et du raisonnement requis.
- Les licences flex sur Teams n’incluent pas Devin Desktop.
- Quand les crédits à la demande sont épuisés, les automatisations s’arrêtent et Devin Review bascule sur un visualiseur de diff sans revue par IA.
