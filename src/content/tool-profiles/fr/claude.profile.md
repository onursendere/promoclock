## Qu’est-ce que Claude ?
Claude est l’assistant d’Anthropic pour la rédaction, l’analyse, la recherche et le code. Il fonctionne dans le navigateur, dans des applications de bureau pour macOS et Windows (Linux est en bêta pour Ubuntu et Debian) et sur iOS et Android. Les développeurs accèdent aux mêmes modèles via l’API Claude.

Les formules payantes incluent Claude Code, l’outil de code agentique d’Anthropic, qui fonctionne dans le terminal, VS Code, les IDE JetBrains et l’application de bureau.

## Points forts
- **Une seule application au lieu de deux modes.** Les fonctions de tâches de Cowork rejoignent les conversations habituelles : vous n’avez plus à choisir où lancer une tâche.
- **Des livrables au-delà du chat.** Claude Design, Slides et Docs transforment une conversation en designs, présentations et documents ; Slides et Docs sont en bêta.
- **Refus de l’entraînement.** Les utilisateurs Free, Pro et Max peuvent refuser que leurs conversations servent à entraîner les modèles.

## Limites
L’utilisation est mesurée par session de cinq heures, avec un plafond hebdomadaire en plus et sans nombre fixe de messages : un travail long ou complexe peut donc atteindre la limite plus tôt que prévu. Anthropic réduit aussi les limites de session aux heures de pointe ; le 6 mai 2026, cette réduction a été supprimée uniquement pour Claude Code sur Pro et Max. Max est uniquement mensuel, Free n’inclut ni Claude Code ni Opus, et la page des tarifs n’affiche aucune réduction étudiante individuelle.
