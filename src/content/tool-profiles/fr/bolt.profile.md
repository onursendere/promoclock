## Qu’est-ce que Bolt.new ?
Bolt.new fonctionne entièrement dans un onglet du navigateur, avec un aperçu en direct de l’application à côté du chat. Vous décrivez ce que vous voulez, puis vous affinez le résultat par prompts, en modifiant directement le code ou en changeant textes et couleurs dans l’aperçu.

## Points forts
Bolt réunit tout le cycle de vie dans un seul onglet : création, audit, publication, achat d’un domaine et connexion à GitHub pour la gestion de versions. Depuis fin août 2026, vous pouvez mettre en file d’attente jusqu’à 20 prompts pendant qu’il travaille, et Bolt Slides sait créer et exporter des présentations.

## Limites
- La consommation de tokens augmente avec la taille du projet et, avec la formule Free, la création par IA se met en pause après 300 000 tokens dans la journée.
- Les prompts et le code passés par Forge sont anonymisés et partagés avec les partenaires de Bolt pour entraîner des modèles open source.
- Un projet lancé pour le web se convertit difficilement en mobile : précisez « application mobile » dès le premier prompt.
- Forge n’est pas disponible dans les formules Teams et Enterprise.
