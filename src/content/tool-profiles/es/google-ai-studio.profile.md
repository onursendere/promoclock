## ¿Qué es Google AI Studio?
Google AI Studio es la consola web en aistudio.google.com donde pruebas modelos Gemini y gestionas claves API de Gemini. Empezó como un playground de prompts y ahora también funciona como constructor de apps.

Google relanzó el modo Build como una herramienta de vibe coding full-stack el 18 de marzo de 2026. En I/O, el 19 de mayo de 2026, sumó proyectos Android nativos, acceso a datos de Google Workspace y exportación a Google Antigravity para desarrollo local.

## Cómo funciona la facturación
- Playground y modo Build son gratis salvo que se enlace una clave API de pago al proyecto.
- El acceso de pago a la API de Gemini empieza con un prepago de $5; los créditos prepagos expiran a los 12 meses.
- Las cuentas de Cloud Billing abiertas después del 2 de marzo de 2026 no pueden gastar los $300 de Google Cloud Welcome en uso de API de Gemini o AI Studio.
- Las suscripciones Google AI Pro y Ultra son una vía aparte para mayores cupos dentro de la interfaz de AI Studio solamente.

## Limitaciones
Google no publica una tabla fija de límites del tier gratis; verificas tus límites de tasa activos dentro de AI Studio. El contenido del tier gratis puede usarse para mejorar productos de Google. Los cupos de suscripción se reinician a diario y no se trasladan a claves API, y los agentes Deep Research y Antigravity Preview en AI Studio requieren una clave API de pago.
