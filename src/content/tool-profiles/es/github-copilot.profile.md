## ¿Qué es GitHub Copilot?
GitHub Copilot ofrece completions, chat y agentes en VS Code, Visual Studio, IDEs de JetBrains, Xcode, Eclipse, Neovim y Zed, en github.com y GitHub Mobile, y en la terminal. La app de escritorio Copilot pasó a estar disponible en todos los planes el 7 de julio de 2026.

## Qué cambió en 2026
- **Facturación basada en uso.** Los conteos de premium requests fueron reemplazados el 1 de junio de 2026 por GitHub AI Credits cobrados a las tarifas de tokens de cada modelo.
- **Flex allotments y Max.** GitHub anunció el 12 de mayo de 2026 que Pro y Pro+ sumarían una asignación variable flex sobre los créditos base, junto con un nuevo plan Max.
- **Pausa de registros.** Los planes de pago individuales estuvieron cerrados a nuevos usuarios del 20 de abril hasta una reapertura gradual iniciada el 17 de junio de 2026.

## Limitaciones
El coste mensual es difícil de predecir: una sesión larga de agente con un modelo frontier quema muchos más créditos que una pregunta rápida a un modelo ligero. La parte flex de cada asignación no es fija. Los usuarios Free y Student no pueden elegir modelos manualmente, y las revisiones de pull request en github.com no forman parte de Copilot Free.
