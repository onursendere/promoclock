## GitHub Copilot क्या है?
GitHub Copilot कंप्लीशन, चैट और एजेंट देता है: VS Code, Visual Studio, JetBrains IDE, Xcode, Eclipse, Neovim और Zed में, github.com और GitHub Mobile पर, और टर्मिनल में। डेस्कटॉप Copilot ऐप 7 जुलाई, 2026 को हर प्लान के लिए उपलब्ध हुआ।

## 2026 में क्या बदला
- **यूसेज-आधारित बिलिंग।** 1 जून, 2026 को प्रीमियम रिक्वेस्ट की गिनती की जगह GitHub AI Credits आए, जो हर मॉडल के टोकन रेट पर चार्ज होते हैं।
- **Flex अलाउंस और Max।** GitHub ने 12 मई, 2026 को घोषणा की कि Pro और Pro+ में बेस क्रेडिट के ऊपर एक वेरिएबल flex अलाउंस जुड़ेगा, साथ में एक नया Max प्लान।
- **साइन-अप पर रोक।** व्यक्तिगत पेड प्लान 20 अप्रैल से नए यूज़र्स के लिए बंद रहे, जब तक 17 जून, 2026 से धीरे-धीरे दोबारा खुलना शुरू नहीं हुआ।

## सीमाएं
मासिक ख़र्च का अंदाज़ा लगाना मुश्किल है: फ़्रंटियर मॉडल पर एक लंबा एजेंट सेशन किसी हल्के मॉडल से पूछे छोटे सवाल से कहीं ज़्यादा क्रेडिट जलाता है। हर अलाउंस का flex हिस्सा तय नहीं है। Free और Student यूज़र मॉडल ख़ुद नहीं चुन सकते, और github.com पर पुल रिक्वेस्ट रिव्यू Copilot Free का हिस्सा नहीं हैं।
