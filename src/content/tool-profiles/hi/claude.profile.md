## Claude क्या है?
Claude, Anthropic का लेखन, विश्लेषण, रिसर्च और कोडिंग के लिए असिस्टेंट है। यह ब्राउज़र में, macOS और Windows के लिए डेस्कटॉप ऐप्स में (Linux, Ubuntu और Debian के लिए बीटा में है), और iOS व Android पर चलता है। डेवलपर्स Claude API के ज़रिए वही मॉडल इस्तेमाल कर सकते हैं।

पेड प्लान्स में Anthropic का एजेंटिक कोडिंग टूल Claude Code बंडल है, जो टर्मिनल, VS Code, JetBrains IDE और डेस्कटॉप ऐप में काम करता है।

## क्या खास है
- **दो मोड की बजाय एक ऐप।** Cowork के टास्क फ़ीचर सामान्य कन्वर्सेशन में शिफ़्ट हो रहे हैं, इसलिए अब आपको यह चुनने की ज़रूरत नहीं कि कोई टास्क कहां जाता है।
- **चैट से आगे का आउटपुट।** Claude Design, Slides और Docs किसी कन्वर्सेशन को डिज़ाइन, डेक और डॉक्यूमेंट में बदल देते हैं; Slides और Docs अभी बीटा में हैं।
- **ट्रेनिंग ऑप्ट-आउट।** Free, Pro और Max यूज़र अपनी चैट को मॉडल ट्रेनिंग में इस्तेमाल होने से ऑप्ट आउट कर सकते हैं।

## सीमाएं
इस्तेमाल हर पांच-घंटे के सेशन के साथ-साथ एक साप्ताहिक कैप में मापा जाता है, बिना किसी फ़िक्स्ड मैसेज काउंट के, इसलिए लंबा या जटिल काम जल्दी लिमिट तक पहुंच सकता है। Anthropic सेशन लिमिट पर पीक-आवर्स रिडक्शन भी लगाता है; 6 मई, 2026 को इसने Pro और Max पर सिर्फ़ Claude Code के लिए यह रिडक्शन हटा दिया। Max सिर्फ़ मंथली है, Free में Claude Code या Opus मॉडल नहीं हैं, और प्राइसिंग पेज पर कोई अलग स्टूडेंट डिस्काउंट लिस्टेड नहीं है।
