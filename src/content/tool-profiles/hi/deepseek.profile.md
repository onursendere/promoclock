## DeepSeek क्या है?
DeepSeek एक हांगझोऊ-आधारित AI लैब भी है और वह फ़्री असिस्टेंट भी जिसे यह ब्राउज़र और मोबाइल ऐप में चलाता है। डेवलपर उसी मॉडल तक कम लागत वाले API से पहुंच सकते हैं या ओपन वेट डाउनलोड करके ख़ुद चला सकते हैं।

## हाल के बदलाव
- **24 अप्रैल, 2026:** V4 Preview ने V4-Pro (1.6T कुल, 49B एक्टिव पैरामीटर) और V4-Flash पेश किए, और 1M कॉन्टेक्स्ट को स्टैंडर्ड बना दिया।
- **24 जुलाई, 2026:** पुराने deepseek-chat और deepseek-reasoner API मॉडल नाम रिटायर हुए।
- **अगस्त 2026:** V4-Pro आम तौर पर उपलब्ध हुआ, और पीक व ऑफ़-पीक API रेट लागू हुए।
- **10 सितंबर, 2026:** V4.1-Flash ने V4-Flash की जगह ली, सस्ती API क़ीमत के साथ।
- **UK:** यह सेवा अब DSeek नाम से चलती है।

## सीमाएं
DeepSeek पर्सनल डेटा चीन में स्टोर करता है, जो इसे रेगुलेटेड या गोपनीय काम के लिए अयोग्य बना सकता है। API में, विज़न इनपुट सिर्फ़ deepseek-flash के साथ काम करता है, और वीकडे पीक विंडो में क़ीमतें दोगुनी हो जाती हैं। 2026 में मॉडल नाम और रूटिंग कई बार बदल चुकी है, इसलिए API यूज़र को डिप्लॉय करने से पहले प्राइसिंग पेज ज़रूर देखना चाहिए।
