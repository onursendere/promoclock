## Murf AI क्या है?
Murf AI स्क्रिप्ट एडिटर पर बना वॉइसओवर टूल है। आप स्क्रिप्ट टाइप या पेस्ट करते हैं, आवाज़ें चुनते हैं, पिच, स्पीड और उच्चारण बारीकी से एडजस्ट करते हैं, और ऑडियो एक्सपोर्ट करते हैं या उसे वीडियो और स्लाइड से सिंक करते हैं। यही आवाज़ें डेवलपर्स को Murf API से भी मिलती हैं।

## क्या खास है
- **नैरेशन के लिए बना।** उच्चारण लाइब्रेरी और प्रति-पंक्ति कंट्रोल ट्रेनिंग और कॉर्पोरेट कंटेंट के लिए ठीक हैं जहां एकरूपता मायने रखती है।
- **अलग प्रोडक्ट, अलग कीमतें।** Studio, Dub और API के अपने-अपने प्लान हैं, इसलिए आप सिर्फ़ उसी हिस्से का भुगतान करते हैं जो इस्तेमाल करते हैं।
