## What is Le Chat (now Vibe)?
Le Chat was Mistral AI's assistant; since May 28, 2026 it has been called Vibe. The same URL and login open a single agent for professional productivity and coding, available on the web, in iOS and Android apps, in VS Code and in the terminal.

## What stands out
- **One licence for work and code.** Chat, Work and Code share a single plan, so Pro covers both the assistant and the coding agent.
- **Visible steps.** Vibe shows each tool call and reasoning chain, and asks for approval before sensitive actions.
- **Teleport.** A live coding session can move between your terminal and the cloud with its history and approvals intact.

## Limitations
The rename split features between Work and Chat, so older Le Chat guides may not match the app, and product documentation has moved to docs.mistral.ai. Free is capped on messages, searches, coding sessions and document storage. Listed prices exclude tax.
