## What is v0?
v0 is an AI agent from Vercel that writes real code for full-stack apps and agents. It can search the web, run terminal commands in its sandbox under Ask, Auto or Full permission modes, and fix its own errors. Finished work publishes to Vercel as a preview or production deployment, with custom domains.

## Who it's for
v0 fits teams already using Next.js and Vercel, since deployments, environment variables and billing run through Vercel. Design systems can be taught to v0 through a custom registry built on shadcn.

## Limitations
- Generation pauses when credits run out, and short prompts can still use many input tokens because project context is included.
- The Free plan's 7 daily messages allow only light testing.
- Opting out of data use for training requires Business or Enterprise.
- The pricing page offers no student, nonprofit or purchasing-power discounts, beyond the separate student program for selected US schools.
