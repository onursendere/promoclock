## What is Replit?
Replit runs everything in the browser: the editor, the AI agent, the database and the hosting. Beyond apps, Core and Pro can also produce slide decks, data visualizations and animated videos. Desktop apps exist for Mac, Windows and Linux, and the iOS and Android apps focus on building websites and web apps from a phone.

## How billing works
Subscriptions include monthly credits that pay for Power and Max Mode requests, publishing, data transfer and database storage. Pro credits roll over for two months, and Cloud prices dropped from August 1, 2026, with autoscale compute falling from $3.20 to $0.60 per million units. When credits run out, pay-as-you-go billing keeps apps running unless you set spending limits.

## Limitations
- Costs combine a subscription with usage-based charges, so heavy agent sessions or busy apps raise the bill.
- Free Mode picks the model for you; choosing a specific model requires Power or Max Mode.
- Agent output is probabilistic, and Replit's pricing page warns it may occasionally make mistakes.
- Native iOS builds need the web app, not the mobile app.
