## What is Claude?
Claude is Anthropic's assistant for writing, analysis, research and coding. It runs in the browser, in desktop apps for macOS and Windows (Linux is in beta for Ubuntu and Debian), and on iOS and Android. Developers reach the same models through the Claude API.

Paid plans bundle Claude Code, Anthropic's agentic coding tool, which works in the terminal, VS Code, JetBrains IDEs and the desktop app.

## What stands out
- **One app instead of two modes.** Cowork's task features are moving into regular conversations, so you no longer choose where a task belongs.
- **Output beyond chat.** Claude Design, Slides and Docs turn a conversation into designs, decks and documents; Slides and Docs are in beta.
- **Training opt-out.** Free, Pro and Max users can opt out of having their chats used for model training.

## Limitations
Usage is measured per five-hour session plus a weekly cap, with no fixed message count, so long or complex work can hit the limit early. Anthropic also applies a peak-hours reduction to session limits; on May 6, 2026 it removed that reduction only for Claude Code on Pro and Max. Max is monthly-only, Free has no Claude Code or Opus, and the pricing page lists no individual student discount.
