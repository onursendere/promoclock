## What is Perplexity?
Perplexity is a search-first assistant: you ask a question, it reads the web and answers with numbered sources. It runs on the web, in iOS and Android apps, in a Mac app and inside Comet, the company's own browser. Developers buy API access separately on a pay-as-you-go basis.

## What stands out
- **Not tied to one AI lab.** A single subscription covers models from OpenAI, Anthropic, Google and others.
- **From answers to deliverables.** Computer can produce reports, spreadsheets, dashboards and simple web apps from one request.
- **A desktop agent on Mac.** Personal Computer, built into Perplexity for Mac (macOS 15 or later), can work with local folders and native apps.

## Limitations
Access to advanced models may be limited during weeks of especially heavy usage, even on Pro. Free has no advanced models or image generation. Computer runs on credits, so big agent jobs can use up Pro's bonus allowance, and API usage is billed separately from any subscription.
