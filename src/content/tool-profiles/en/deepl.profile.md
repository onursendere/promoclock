## What is DeepL?
DeepL began as a web translator and now sells a bundle of language tools: Translator, Write, Voice and an API. The free translator works in the browser, desktop apps and mobile apps without a subscription, while DeepL Pro is billed per user.

## Plans at a glance
- **Individual**: one user, 300,000 characters and 3 file translations a month.
- **Team**: 1,000,000 characters per user, 20 files, bulk file translation, analytics, SSO for 50+ users.
- **Business**: unlimited characters under a fair usage policy, 100 files, translation memory, domain capture and Write Pro.
- **Enterprise**: custom character and file limits, bring your own key, 99.9% availability and a dedicated account team.

## Limitations
The free terms allow DeepL to process submitted text to improve its models, so confidential material belongs on a paid plan. File quotas are tight at the bottom: 1 file a month free, 3 on Individual. Write Pro is a paid add-on unless you are on Business, and Voice is capped at 30 minutes per user each month. Prices are shown in local currency, so the same plan appears in euros or pounds outside the US.
