## What is Base44?
Base44 is an AI builder for apps, websites and agents that runs entirely in the browser or its mobile apps. It handles the frontend, backend, data and hosting in one place, and Wix has owned it since June 2025.

Developers can also work outside the chat: Base44 offers a JavaScript SDK, a CLI and a backend service they can connect to React, Vue or React Native projects.

## How credits work
Each prompt costs message credits based on how much the AI has to change, and costs are calculated after the action runs. A small text tweak is about 0.5 credits, while an app-wide change can take 3–4. Previewing and clicking through your app is free, and so are manual visual edits in the editor.

## Limitations
- The Free plan's 5-credit daily cap makes longer build sessions impractical.
- Credit costs are calculated only after an action runs, so spending is hard to predict.
- GitHub integration, backend functions, model selection and code export start on Builder at $50/month.
- Connecting a domain and managing app security aren't available from a mobile browser.
