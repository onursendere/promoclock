## What is GitHub Copilot?
GitHub Copilot offers completions, chat and agents in VS Code, Visual Studio, JetBrains IDEs, Xcode, Eclipse, Neovim and Zed, on github.com and GitHub Mobile, and in the terminal. The desktop Copilot app became available on every plan on July 7, 2026.

## What changed in 2026
- **Usage-based billing.** Premium request counts were replaced on June 1, 2026 by GitHub AI Credits charged at each model's token rates.
- **Flex allotments and Max.** GitHub announced on May 12, 2026 that Pro and Pro+ would add a variable flex allotment on top of base credits, alongside a new Max plan.
- **Sign-up pause.** Individual paid plans were closed to new users from April 20 until a gradual reopening starting June 17, 2026.

## Limitations
Monthly cost is hard to predict: a long agent session on a frontier model burns far more credits than a quick question to a lightweight model. The flex part of each allowance is not fixed. Free and Student users cannot choose models manually, and pull request reviews on github.com are not part of Copilot Free.
