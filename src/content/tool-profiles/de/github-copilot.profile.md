## Was ist GitHub Copilot?
GitHub Copilot bietet Vervollständigungen, Chat und Agenten in VS Code, Visual Studio, JetBrains-IDEs, Xcode, Eclipse, Neovim und Zed, auf github.com und GitHub Mobile sowie im Terminal. Die Copilot-Desktop-App wurde am 7. Juli 2026 in jedem Plan verfügbar.

## Was sich 2026 änderte
- **Nutzungsbasierte Abrechnung.** Premium-Request-Zählungen wurden am 1. Juni 2026 durch GitHub AI Credits ersetzt, abgerechnet zu den Token-Tarifen jedes Modells.
- **Flex-Kontingente und Max.** GitHub kündigte am 12. Mai 2026 an, dass Pro und Pro+ ein variables Flex-Kontingent zusätzlich zu den Basis-Credits erhalten, neben einem neuen Max-Plan.
- **Anmelde-Pause.** Individuelle Bezahlpläne waren ab dem 20. April für neue Nutzer geschlossen, bis zur schrittweisen Wiederöffnung ab dem 17. Juni 2026.

## Grenzen
Die Monatskosten sind schwer vorhersehbar: eine lange Agent-Sitzung auf einem Frontier-Modell verbrennt weit mehr Credits als eine schnelle Frage an ein leichtgewichtiges Modell. Der Flex-Teil jedes Kontingents ist nicht fix. Free- und Student-Nutzer können Modelle nicht manuell wählen, und Pull-Request-Reviews auf github.com gehören nicht zu Copilot Free.
