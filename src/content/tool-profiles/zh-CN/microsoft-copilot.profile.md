## Microsoft Copilot是什么？
Microsoft Copilot是微软用于聊天、图片、文件和办公任务的助手。它可在copilot.com、Windows和Mac桌面应用，以及iOS和Android应用中使用。用工作账号登录时会切换到你所在组织的Copilot；个人和工作数据保持分离。

## 2026年发生了哪些变化
- Microsoft 365 Copilot app更名为Microsoft Copilot app，消费者的聊天记录和内容合并进了这一个应用。
- Podcasts、Group Chat和面向消费者的Deep Research于2026年8月18日下线。
- Copilot Tasks迁移到了Cowork；Personal和Family用户可以查看旧任务，但必须升级才能运行新任务。
- Microsoft 365 Pro现以每月$99.99位居个人产品线顶端，拥有最高的AI用量上限。

## 局限性
AI功能只属于订阅账号本人，无法共享，Microsoft 365 Basic完全不含AI功能。每个套餐都有用量限制和AI额度，用完后功能会暂停直到重置。Pro只支持按月计费，Cowork的远程浏览器功能尚未就绪——网页操作要通过你自己设备上的Microsoft Edge进行。
