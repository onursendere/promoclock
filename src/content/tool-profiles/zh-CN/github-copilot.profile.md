## GitHub Copilot是什么？
GitHub Copilot在VS Code、Visual Studio、JetBrains系列IDE、Xcode、Eclipse、Neovim和Zed中提供代码补全、聊天和智能体功能，也能在github.com、GitHub Mobile和终端中使用。桌面版Copilot应用已于2026年7月7日面向所有套餐开放。

## 2026年有哪些变化
- **按用量计费。** 2026年6月1日起，原有的高级请求次数被按各模型代币费率收费的GitHub AI额度取代。
- **弹性额度与Max套餐。** GitHub于2026年5月12日宣布，Pro和Pro+将在基础额度之上新增可变的弹性额度，并推出全新的Max套餐。
- **注册暂停。** 个人付费套餐自4月20日起对新用户关闭，直到2026年6月17日才开始逐步重新开放。

## 局限性
每月费用难以预测：在前沿模型上进行一次长时间的智能体会话，比向轻量模型提一个简单问题消耗多得多的额度。每份额度中的弹性部分并不固定。Free和Student用户无法手动选择模型，github.com上的拉取请求审查功能也不包含在Copilot Free中。
