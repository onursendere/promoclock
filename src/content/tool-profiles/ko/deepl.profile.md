## DeepL이란?
DeepL은 웹 번역기로 시작해 지금은 Translator, Write, Voice, API를 묶은 언어 도구 모음을 판매합니다. 무료 번역기는 구독 없이 브라우저, 데스크톱 앱, 모바일 앱에서 작동하며, DeepL Pro는 사용자 단위로 과금됩니다.

## 플랜 한눈에 보기
- **Individual**: 사용자 1명, 월 30만 자와 파일 번역 3건.
- **Team**: 사용자당 100만 자, 파일 20개, 대량 파일 번역, 분석, 50명 이상을 위한 SSO.
- **Business**: 공정 사용 정책 아래 무제한 글자 수, 파일 100개, 번역 메모리, 도메인 캡처, Write Pro.
- **Enterprise**: 맞춤형 글자·파일 한도, 자체 키 사용, 99.9% 가용성, 전담 계정 팀.

## 한계
무료 이용 약관은 DeepL이 제출된 텍스트를 모델 개선에 처리할 수 있도록 허용하므로, 기밀 자료는 유료 플랜에서 다루어야 합니다. 파일 할당량은 하위 등급에서 빠듯합니다. 무료는 월 1개 파일, Individual은 3개입니다. Write Pro는 Business가 아니라면 유료 애드온이며, Voice는 사용자당 월 30분으로 제한됩니다. 가격은 현지 통화로 표시되므로 미국 밖에서는 같은 플랜이 유로나 파운드로 나타납니다.
