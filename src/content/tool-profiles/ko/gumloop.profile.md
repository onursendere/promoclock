## Gumloop란?
Gumloop를 사용하면 코드 없이 AI 에이전트를 만들고, MCP 기반 커넥터로 앱에 연결해, Gumloop 채팅, Slack, Microsoft Teams, 에이전트 전용 이메일 받은 편지함, 호스팅 페이지처럼 업무가 이미 이루어지는 곳에서 실행할 수 있습니다. 35개 이상의 모델을 지원하며 자체 제공업체 키를 사용할 수도 있습니다.

## 과금 방식
Gumloop는 에이전트가 실제로 한 일에 대해 청구하므로, 같은 에이전트라도 간단한 질문은 2 크레딧, 심층 리서치는 200 크레딧이 들 수 있습니다. Pro의 월 20,000 크레딧은 정가 $0.005 기준 7,400 크레딧에 보너스 12,600 크레딧을 더한 것입니다. 실시간 누적 합계가 채팅 헤더에 표시되며 선택하면 크레딧 유형별 내역이 열립니다.

## 한계
- 무료 플랜이 없으며 셀프서비스 옵션은 월 $37의 Pro뿐입니다.
- 채팅당 비용이 달라지며, 에이전트 전반의 지출을 추적하는 Insights 대시보드는 Enterprise 전용입니다.
- 자체 API 키를 쓰면 오케스트레이션 수수료가 16%로 두 배가 됩니다.
- 사용하지 않은 Pro 크레딧은 결제 기간마다 소멸하고, 기존 워크플로 빌더는 이제 레거시로 표시됩니다.
