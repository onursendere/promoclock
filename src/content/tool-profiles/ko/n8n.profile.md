## n8n이란?
n8n은 기술 사용자를 겨냥한 워크플로 자동화 도구입니다. 워크플로는 500개 이상 앱용 기본 노드, 커스텀 HTTP 요청, 코드를 섞어 구성하며, AI 모델을 호출하거나 사람의 승인 단계가 포함된 완전한 에이전트를 실행할 수 있습니다. 같은 제품이 호스팅 서비스로도, 자체 서버에서도 동작하며 새 버전이 매주 출시됩니다. 2.40 버전은 2026년 9월 15일에 나왔습니다.

## 클라우드냐 셀프호스팅이냐
- **n8n Cloud**는 호스팅을 대신 처리하며, Starter와 Pro 플랜이 월간 실행 횟수 기준으로 과금됩니다.
- **Community Edition**은 무료 셀프호스팅 버전으로, 이메일을 등록하면 편집기에서 폴더와 디버깅 기능이 열립니다.
- **Business와 Enterprise**는 자체 인프라에서도 SSO, 환경 분리, Git 버전 관리를 추가로 제공합니다.

## 한계
셀프호스팅은 소프트웨어를 설치, 보안 관리, 업데이트할 기술이 필요합니다. Cloud에는 영구 무료 요금제가 없고, Starter는 동시 실행 5개와 공유 프로젝트 1개로 제한됩니다. 셀프호스팅용 Business 플랜은 월 수백 유로에 달합니다. 표시되는 가격은 지역에 따라 달라져서, 예를 들어 영국 방문자에게는 유로 대신 파운드로 표시됩니다.
