## remove.bg란?
remove.bg는 2021년 Canva의 일부가 된 자동 배경 제거 도구입니다. 웹사이트, Windows·Mac·Linux 데스크톱 앱, API, Photoshop과 Figma 같은 플러그인으로 작동합니다.

## 2026년 12월 서비스 종료
Canva는 두 개의 별도 도구를 운영하는 대신 remove.bg를 자사 제품에 통합합니다. 2026년 12월 1일 오전 9시(CET)부터 웹사이트, 계정, 셀프서비스 API, 데스크톱 앱, 플러그인이 작동을 멈춥니다.

- 단일 이미지와 대량 일괄 처리: 웹 또는 Canva 데스크톱 앱의 Canva 배경 제거 도구.
- 대용량 자동화: Leonardo.ai의 API이며 셀프서비스 사용자를 위한 이전 가이드가 있습니다.
- 엔터프라이즈 API 고객: 계약이 그대로 유지됩니다.
