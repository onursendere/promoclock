## Perplexity란?
Perplexity는 검색 우선 어시스턴트입니다. 질문을 하면 웹을 읽고 번호가 매겨진 출처와 함께 답합니다. 웹, iOS·Android 앱, Mac 앱, 그리고 회사 자체 브라우저인 Comet 안에서 작동합니다. 개발자는 API 접근을 사용량 기반으로 별도 구매합니다.

## 무엇이 돋보이나
- **한 AI 연구소에 묶이지 않음.** 하나의 구독으로 OpenAI, Anthropic, Google 등의 모델을 이용할 수 있습니다.
- **답변에서 결과물로.** Computer는 한 번의 요청으로 리포트, 스프레드시트, 대시보드, 간단한 웹 앱까지 만들어냅니다.
- **Mac용 데스크톱 에이전트.** macOS 15 이상에서 동작하는 Perplexity for Mac에 내장된 Personal Computer는 로컬 폴더와 네이티브 앱과 함께 작동할 수 있습니다.

## 한계
사용량이 특히 많은 주간에는 Pro에서도 고급 모델 접근이 제한될 수 있습니다. Free에는 고급 모델이나 이미지 생성이 없습니다. Computer는 크레딧으로 작동하므로 큰 에이전트 작업이 Pro의 보너스 한도를 빠르게 소진할 수 있고, API 사용량은 구독과 별도로 청구됩니다.
