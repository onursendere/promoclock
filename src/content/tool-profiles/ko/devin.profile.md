## Devin이란?
Devin은 Cognition의 자율 코딩 에이전트로, 복잡한 다중 저장소 프로젝트를 다루는 엔지니어링 팀을 겨냥합니다. 코드베이스의 관례를 익히고 자체 머신에서 작업을 처리하며 리뷰를 위해 풀 리퀘스트를 반환합니다.

## 하나의 제품, 여러 표면
Cognition은 2026년에 두 제품을 통합했습니다. Windsurf.com은 이제 Devin Desktop으로 리디렉션되며, 이는 Windsurf와 VS Code 설정과 호환되고 에이전트 관리자로 시작되는 완전한 IDE입니다. Devin Cloud는 원격에서 장시간 작업을 처리하고, Devin CLI는 터미널에서 실행되며, Devin Review는 코드 리뷰를 담당합니다. 하나의 구독 할당량이 Devin 세션, CLI, Devin Desktop 전체에 공유됩니다.

## 한계
- Free 플랜에는 클라우드 에이전트가 포함되지 않습니다.
- 할당량은 고정된 숫자로 공개되지 않으며, 메시지당 비용은 모델, 작업 크기, 필요한 추론량에 따라 달라집니다.
- Teams의 플렉스 좌석에는 Devin Desktop이 포함되지 않습니다.
- 온디맨드 크레딧이 소진되면 Automations가 멈추고 Devin Review는 AI 리뷰 없는 diff 뷰어로 전환됩니다.
