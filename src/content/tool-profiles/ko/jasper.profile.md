## Jasper란?
Jasper는 마케팅 업무를 위해 만든 AI 플랫폼입니다. 빈 챗봇 대신 AI 모델 주변에 목소리, 스타일 가이드, 오디언스 프로필, 제품 지식 같은 브랜드 맥락을 두르고 이를 모든 초안에 적용합니다.

홈페이지는 이제 Jasper를 에이전트 워크스페이스라고 부릅니다. Canvas는 일상적인 콘텐츠를, Grid는 대규모 제작을, Studio는 맞춤 앱 제작을 맡고, MCP 서버는 Jasper의 맥락을 다른 AI 도구에 연결합니다.

## 추천 대상
Jasper는 여러 사람이 하나의 브랜드 보이스로 글을 써야 하는 마케팅 부서와 에이전시에 적합합니다. 1인 마케터도 Pro를 쓸 수 있지만 가격은 전문적인 사용을 전제로 합니다.

## 한계
- 무료 플랜이 없고, Pro는 1좌석과 Brand Voice 2개로 제한됩니다.
- API 접근, 맞춤 에이전트, Grid, SSO, 무제한 브랜드 자산은 맞춤 가격의 Business 플랜이 필요합니다.
- 크레딧 기반 기능 때문에 GEO, Grid, API를 많이 쓰면 총비용을 예측하기 어렵습니다.
- 브라우저 확장 프로그램은 Chrome과 Edge만 지원합니다.
