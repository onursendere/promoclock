## DeepSeek이란?
DeepSeek은 항저우에 본사를 둔 AI 연구소이자, 브라우저와 모바일 앱에서 운영하는 무료 어시스턴트를 동시에 가리킵니다. 개발자는 저렴한 API를 통해 같은 모델에 접근하거나 오픈웨이트를 내려받아 직접 실행할 수 있습니다.

## 최근 변경 사항
- **2026년 4월 24일:** V4 프리뷰가 V4-Pro(총 1.6T, 활성 파라미터 490억)와 V4-Flash를 선보였고 100만 컨텍스트를 표준으로 만들었습니다.
- **2026년 7월 24일:** 예전 API 모델명인 deepseek-chat과 deepseek-reasoner가 지원 종료됐습니다.
- **2026년 8월:** V4-Pro가 정식 출시됐고 피크·비피크 API 요금이 적용되기 시작했습니다.
- **2026년 9월 10일:** V4.1-Flash가 더 저렴한 API 가격으로 V4-Flash를 대체했습니다.
- **영국:** 서비스명이 DSeek으로 바뀌었습니다.

## 한계
DeepSeek은 개인 데이터를 중국에 저장하므로 규제 대상 업무나 기밀 작업에는 적합하지 않을 수 있습니다. API에서 시각 입력은 deepseek-flash에서만 작동하며, 평일 피크 시간대에는 가격이 두 배가 됩니다. 2026년 들어 모델명과 라우팅이 여러 차례 바뀌었으므로 API 사용자는 배포 전에 요금 페이지를 확인해야 합니다.
