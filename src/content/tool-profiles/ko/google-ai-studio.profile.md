## Google AI Studio란?
Google AI Studio는 Gemini 모델을 시험해 보고 Gemini API 키를 관리하는 aistudio.google.com의 웹 콘솔입니다. 처음에는 프롬프트 플레이그라운드로 시작했으나 이제 앱 빌더 역할도 겸합니다.

구글은 2026년 3월 18일 Build 모드를 완전한 풀스택 바이브 코딩 도구로 재출시했습니다. 2026년 5월 19일 I/O에서는 네이티브 안드로이드 프로젝트, Google Workspace 데이터 접근, 로컬 개발을 위한 Google Antigravity 내보내기를 추가했습니다.

## 결제 방식
- Playground와 Build 모드는 프로젝트에 유료 API 키가 연결되지 않는 한 무료입니다.
- 유료 Gemini API 접근은 $5 선불 결제로 시작하며 선불 크레딧은 12개월 후 만료됩니다.
- 2026년 3월 2일 이후 개설된 Cloud Billing 계정은 $300 Google Cloud Welcome 크레딧을 Gemini API나 AI Studio 사용에 쓸 수 없습니다.
- Google AI Pro와 Ultra 구독은 AI Studio 인터페이스 안에서만 더 높은 할당량을 받는 별도의 경로입니다.

## 한계
구글은 고정된 무료 등급 한도 표를 공개하지 않으므로 AI Studio 안에서 현재 속도 제한을 직접 확인해야 합니다. 무료 등급 콘텐츠는 구글 제품 개선에 쓰일 수 있습니다. 구독 할당량은 매일 재설정되며 API 키로는 이월되지 않고, AI Studio의 Deep Research와 Antigravity Preview 에이전트는 유료 API 키가 필요합니다.
