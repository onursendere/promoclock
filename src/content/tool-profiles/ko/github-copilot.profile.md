## GitHub Copilot이란?
GitHub Copilot은 VS Code, Visual Studio, JetBrains IDE, Xcode, Eclipse, Neovim, Zed, github.com, GitHub Mobile, 터미널에서 완성, 채팅, 에이전트를 제공합니다. 데스크톱 Copilot 앱은 2026년 7월 7일 모든 플랜에서 이용 가능해졌습니다.

## 2026년에 바뀐 점
- **사용량 기반 청구.** 2026년 6월 1일 프리미엄 요청 횟수가 각 모델의 토큰 요율로 청구되는 GitHub AI 크레딧으로 대체됐습니다.
- **플렉스 할당량과 Max.** GitHub는 2026년 5월 12일 Pro와 Pro+에 기본 크레딧 위에 가변적인 플렉스 할당량이 추가되고 새로운 Max 플랜이 생긴다고 발표했습니다.
- **가입 일시 중단.** 개인 유료 플랜은 4월 20일부터 신규 사용자에게 닫혔다가 2026년 6월 17일부터 단계적으로 다시 열렸습니다.

## 한계
월간 비용을 예측하기 어렵습니다. 프런티어 모델로 진행하는 긴 에이전트 세션은 경량 모델에 대한 간단한 질문보다 훨씬 많은 크레딧을 소모합니다. 각 할당량의 플렉스 부분은 고정되어 있지 않습니다. Free와 Student 사용자는 모델을 수동으로 선택할 수 없고, github.com의 풀 리퀘스트 리뷰는 Copilot Free에 포함되지 않습니다.
