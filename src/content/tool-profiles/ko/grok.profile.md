## Grok란?
Grok는 grok.com, iOS와 Android 앱, X 안에서 이용하는 SpaceXAI의 어시스턴트입니다. 채팅 외에도 계정 하나로 이미지·영상용 Grok Imagine, 음성 대화, Grok Build 코딩 에이전트를 쓸 수 있고, SuperGrok부터는 Grok Bot 에이전트도 포함됩니다. 현재 플랜은 Grok 4.6 모델을 내세웁니다.

## 플랜 구성
개인용 등급은 Free, SuperGrok Lite, SuperGrok, SuperGrok Plus, SuperGrok Heavy의 다섯 가지입니다. 유료 등급은 2026년 6월에 단일 주간 사용량 풀로 바뀌었기 때문에, 높은 등급은 주로 더 큰 풀, 더 빠른 응답, 더 높은 영상 해상도를 제공합니다. Grok Bot은 유료 개인용 Cursor 플랜에도 포함됩니다.

## 한계
- 공개 요금 페이지에 가격이 있는 것은 SuperGrok과 SuperGrok Plus뿐입니다.
- 모든 Imagine 결과물에 워터마크가 붙고, 등급의 720p 상한에 도달하면 720p 영상은 480p로 낮아집니다.
- 컴패니언은 iOS 앱에서만 제공됩니다.
- 추가 사용 크레딧은 현재 웹에서만 구매할 수 있으며 구매 후 1년이 지나면 만료됩니다.
