## Warp란?
Warp는 더 빠른 터미널로 시작해 지금은 에이전틱 개발 환경을 표방합니다. 같은 앱이 일상적인 셸 작업과 코드를 작성·실행·수정하는 에이전트 세션을 모두 처리합니다.

2026년 4월 Warp는 클라이언트를 오픈소스화했고, 2026년 8월에는 소프트웨어 수명 주기 전반에서 다수의 코딩 에이전트를 운영하는 기업을 위해 Warp Factories를 출시했습니다. 터미널은 여전히 독립된 제품으로 유지·관리됩니다.

## 플랜 활용법
Free는 터미널만 필요하거나 이미 다른 곳에서 모델 접근 비용을 지불하는 사람에게 적합합니다. Build와 Max는 에이전트 사용량, 무제한 Warp Drive 객체, 클라우드 대화 저장을 번들로 제공합니다. Business는 SAML SSO, 팀 사용량 지표, 관리자 데이터 통제를 추가합니다.

## 한계
- Free 플랜에는 번들 AI 사용량이 없습니다.
- 크레딧은 API 요금 기준으로 소모되므로 에이전트 사용량이 많으면 Build의 $20 한도를 빠르게 초과할 수 있습니다.
- Business는 셀프서브 팀을 최대 25석으로 제한하며, 그보다 큰 조직은 Enterprise가 필요합니다.
- Warp Factories는 얼리 액세스 단계이며 아직 일반 공개되지 않았습니다.
