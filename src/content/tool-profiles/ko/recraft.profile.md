## Recraft란?
Recraft는 브라우저 버전과 크레딧·프로젝트를 공유하는 iOS·Android 앱을 갖춘 웹 기반 디자인 스튜디오입니다. 래스터 이미지와 편집 가능한 벡터를 모두 출력하는 자체 모델을 중심으로 만들어졌으며 같은 캔버스에서 외부 이미지·비디오 모델도 제공합니다.

## 눈에 띄는 점
- **진짜 벡터.** Vector 모델은 편집 가능한 SVG 파일을 반환해 깔끔하게 확대되어야 하는 로고, 아이콘, 일러스트에 알맞습니다.
- **디자인 도구다운 발상.** 스타일, 프레임, 색상 팔레트, 목업, 인쇄 설정이 생성 기능 바로 옆에 있습니다.
- **연동.** Figma, Framer, Google Workspace용 플러그인과 에이전트가 직접 Recraft를 호출할 수 있는 MCP 서버가 있습니다.

## 한계
Free 플랜은 주로 테스트용입니다. 이미지가 공개되고 상업적으로 쓸 수 없기 때문입니다. 월간 구독 크레딧은 이월되지 않고 추가 크레딧은 유료 사용자에게만 판매되며, 모바일 앱의 비디오 생성은 구독자로 제한됩니다. Teams는 최소 2석이 필요하고 멤버별 월간 크레딧은 공유할 수 없습니다.
