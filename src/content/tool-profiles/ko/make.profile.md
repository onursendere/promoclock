## Make란?
Make는 자동화를 시각적 시나리오로 구성합니다. 시나리오 안의 각 모듈은 앱에서 데이터를 읽거나 생성하거나 변형하며, 라우터와 필터, 반복기가 레코드가 흐르는 방식을 결정합니다. 시나리오는 일정에 따라, 웹훅을 통해 즉시, 또는 다른 시나리오가 호출하는 서브시나리오로 실행됩니다.

## 요금제 한눈에 보기
유료 등급은 월 10,000개부터 최대 800만 개까지 구매하는 크레딧 양에 따라 가격이 매겨지며, 모든 등급이 동일하게 3,000개 이상의 앱을 지원합니다.

- **Core**는 무제한 활성 시나리오, 분 단위 예약, Make API 접근을 추가합니다.
- **Pro**는 우선 실행, 커스텀 변수, 전체 텍스트 실행 로그 검색을 추가합니다.
- **Teams**는 팀 역할과 공유 시나리오 템플릿을 추가하며, Enterprise는 커스텀 함수와 온프레미스 접근을 더합니다.

## 한계
Free 플랜은 시나리오 실행 시간이 5분, 파일 크기가 5MB로 제한돼 무거운 작업에는 적합하지 않으며, 유료 시나리오도 40분에서 멈춥니다. Make AI Agents와 AI Web Search는 2026년 9월 기준 가격 페이지에 베타로 표시되어 있습니다. 한 번의 실행이 소모하는 크레딧은 2개부터 수천 개까지 다양해서, 긴 목록을 반복 처리하면 비용이 빠르게 늘어날 수 있습니다.
