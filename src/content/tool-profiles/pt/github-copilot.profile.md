## O que é o GitHub Copilot?
O GitHub Copilot oferece completions, chat e agentes no VS Code, Visual Studio, IDEs JetBrains, Xcode, Eclipse, Neovim e Zed, no github.com e no GitHub Mobile, e no terminal. O app de desktop do Copilot ficou disponível para todo plano em 7 de julho de 2026.

## O que mudou em 2026
- **Cobrança baseada em uso.** As contagens de Premium requests foram substituídas em 1º de junho de 2026 pelos GitHub AI Credits, cobrados nas taxas de token de cada modelo.
- **Flex allotments e Max.** O GitHub anunciou em 12 de maio de 2026 que Pro e Pro+ ganhariam uma cota flexível variável além dos créditos base, junto com um novo plano Max.
- **Pausa nas assinaturas.** Os planos individuais pagos ficaram fechados a novos usuários de 20 de abril até uma reabertura gradual a partir de 17 de junho de 2026.

## Limitações
O custo mensal é difícil de prever: uma sessão longa de agente em um modelo de ponta consome muito mais créditos do que uma pergunta rápida a um modelo leve. A parte flexível de cada cota não é fixa. Usuários Free e Student não podem escolher modelos manualmente, e revisões de pull request no github.com não fazem parte do Copilot Free.
