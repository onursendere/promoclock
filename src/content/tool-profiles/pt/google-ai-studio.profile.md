## O que é o Google AI Studio?
Google AI Studio é o console web em aistudio.google.com onde você testa modelos Gemini e gerencia chaves de API Gemini. Começou como um playground de prompts e agora também funciona como criador de apps.

O Google relançou o modo Build como uma ferramenta completa de vibe coding full-stack em 18 de março de 2026. No I/O, em 19 de maio de 2026, adicionou projetos Android nativos, acesso a dados do Google Workspace e exportação para o Google Antigravity para desenvolvimento local.

## Como funciona a cobrança
- O Playground e o modo Build são gratuitos, a menos que uma chave de API paga esteja vinculada ao projeto.
- O acesso pago à API Gemini começa com um pré-pagamento de $5; os créditos pré-pagos expiram após 12 meses.
- Contas de Cloud Billing abertas depois de 2 de março de 2026 não podem usar o crédito de boas-vindas de $300 do Google Cloud na API Gemini ou no AI Studio.
- As assinaturas Google AI Pro e Ultra são uma via separada para cotas mais altas, só dentro da interface do AI Studio.

## Limitações
O Google não publica uma tabela fixa de limites do nível gratuito; você confere seus limites de taxa ativos dentro do AI Studio. O conteúdo do nível gratuito pode ser usado para melhorar produtos do Google. As cotas de assinatura renovam diariamente e não passam para as chaves de API, e os agentes Deep Research e Antigravity Preview no AI Studio exigem uma chave de API paga.
