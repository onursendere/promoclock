## O que é o Claude?
O Claude é o assistente da Anthropic para escrita, análise, pesquisa e programação. Ele roda no navegador, em apps desktop para macOS e Windows (Linux está em beta para Ubuntu e Debian), e em iOS e Android. Desenvolvedores acessam os mesmos modelos pela Claude API.

Os planos pagos incluem o Claude Code, a ferramenta de programação com agente da Anthropic, que funciona no terminal, no VS Code, em IDEs JetBrains e no app desktop.

## O que se destaca
- **Um app em vez de dois modos.** Os recursos de tarefas do Cowork estão migrando para as conversas normais, então você não precisa mais escolher onde uma tarefa se encaixa.
- **Saída além do chat.** O Claude Design, Slides e Docs transformam uma conversa em designs, apresentações e documentos; Slides e Docs estão em beta.
- **Opção de não usar dados para treino.** Usuários Free, Pro e Max podem optar por não ter seus chats usados para treinar os modelos.

## Limitações
O uso é medido por sessão de cinco horas mais um limite semanal, sem um número fixo de mensagens, então trabalhos longos ou complexos podem atingir o limite mais cedo. A Anthropic também aplica uma redução nos limites de sessão em horários de pico; em 6 de maio de 2026 ela removeu essa redução só para o Claude Code no Pro e no Max. O Max é só mensal, o Free não tem Claude Code nem modelos Opus, e a página de preços não lista um desconto individual para estudantes.
