## O que é o remove.bg?
O remove.bg é um removedor de fundo automático que passou a fazer parte do Canva em 2021. Ele funciona no site, em apps de desktop para Windows, Mac e Linux, por API e por plugins como Photoshop e Figma.

## O fechamento de dezembro de 2026
A Canva está incorporando o remove.bg aos seus próprios produtos em vez de manter duas ferramentas separadas. A partir de 1º de dezembro de 2026 às 9h CET, o site, as contas, a API self-service, os apps de desktop e os plugins param de funcionar.

- Imagens únicas e lotes: o Background Remover do Canva, na web ou no app de desktop do Canva.
- Automação de alto volume: a API da Leonardo.ai, com um guia de migração para usuários self-service.
- Clientes de API empresariais: os contratos continuam sem mudanças.

## Limitações
- Relatórios de uso e faturas não podem ser baixados depois que as contas fecharem, então exporte-os antes.
- Os créditos da assinatura nunca acumulam para o mês seguinte.
- Uma nova assinatura agora compra só alguns meses de serviço antes do fechamento.
- A Canva lista o Background Remover como um recurso pago do Pro, então a substituição não é um pacote de créditos equivalente.
