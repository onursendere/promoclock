## Microsoft Copilotとは？
Microsoft Copilotは、チャット、画像、ファイル、業務タスクを扱うMicrosoftのアシスタントです。copilot.com、WindowsとMacのデスクトップアプリ、iOSとAndroidアプリで動作します。業務用アカウントでサインインすると組織のCopilotに切り替わり、個人データと業務データは分離されたままです。

## 2026年の変更点
- Microsoft 365 Copilotアプリは単にMicrosoft Copilotアプリとなり、個人向けチャットとコンテンツが統合されました。
- Podcasts、Group Chat、個人向けDeep Researchは2026年8月18日に廃止されました。
- Copilot TasksはCoworkに移行し、PersonalとFamilyの契約者は過去のタスクを閲覧できますが、新規実行にはアップグレードが必要です。
- Microsoft 365 Proは月$99.99で個人向けラインナップの最上位となり、AI利用上限も最大です。

## 制限事項
AI機能は契約者本人に紐づき共有できず、Microsoft 365 Basicには機能そのものがありません。すべてのプランに利用上限とAIクレジットがあり、リセットされるまで機能が一時停止します。Proは月払いのみで、Coworkのリモートブラウザはまだ準備段階のため、Web操作はあなた自身の端末上のMicrosoft Edgeを介して行われます。
