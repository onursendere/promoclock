## GitHub Copilotとは？
GitHub Copilotは、VS Code、Visual Studio、JetBrains系IDE、Xcode、Eclipse、Neovim、Zed、github.comとGitHub Mobile、そしてターミナルで補完、チャット、エージェントを提供します。デスクトップ版のCopilotアプリは2026年7月7日に全プランで利用可能になりました。

## 2026年の変更点
- **従量課金への移行。** Premiumリクエスト数は2026年6月1日をもって、各モデルのトークン単価で課金されるGitHub AI Creditsに置き換えられました。
- **フレックス割当とMax。** GitHubは2026年5月12日、ProとPro+に基本クレジットに加えて変動するフレックス割当を追加し、新しいMaxプランを発表すると発表しました。
- **新規登録の一時停止。** 個人向け有料プランは4月20日から6月17日にかけての段階的な再開まで、新規ユーザーへの登録を停止していました。

## 制限事項
月々のコストは予測しにくく、フロンティアモデルでの長いエージェントセッションは軽量モデルへの簡単な質問よりはるかに多くのクレジットを消費します。各割当のフレックス部分は固定ではありません。FreeとStudentのユーザーはモデルを手動で選べず、github.com上のプルリクエストレビューはCopilot Freeには含まれません。
