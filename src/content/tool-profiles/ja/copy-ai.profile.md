## Copy.aiとは？
Copy.aiはGo-to-Marketチーム向けのAIプラットフォームです。複数のAIモデルを使うチャットと、調査・執筆・データ処理のステップを組み合わせたワークフローを組み合わせ、チーム全体で再利用できるプロセスを作ります。

Fullcastは2025年10月からCopy.aiを所有しています。ヘルプ記事は現在Fullcastのサポートサイトに移管されており、Fullcastは自社のレベニューオペレーションスイートの一部として製品を販売しています。

## 誰に向いているか
AIチャットを共有したいだけの小規模チームは、5席を含むChatプランから始められます。クレジット制の上位プランは、見込み客開拓、リード処理、コンテンツ制作を自動化したい大規模なレベニュー組織向けです。

## 制限事項
- 現行の料金ページには無料プランや公開されている無料トライアルがありません。
- 月$29のChatの次のプランはGrowthの月$1,000で、中間の価格帯がありません。
- クレジット消費量はワークフローの複雑さに左右され、コストの予測が難しくなります。
- API アクセスはEnterpriseにしか掲載されていません。
